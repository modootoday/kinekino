# 전체 요구사항 추적표 — 설계 기준선

2026-10-26. ID는 표시 제품명·문서 경로와 독립이다. 아래 40개는 요구사항군이며 실제 기능/시험/완료 개수가 아니다. 전체 범위 진입점인 [통합 gate](../full-product-integration-gates.md), [SDK 계약](../../../sots/player/application/api/sdk-contract.md), [AI 범위](../../../sots/player/application/analysis/scope.md), [제작 범위](../../../sots/player/application/production/scope.md), [Meari queue](../../../../packages/meari/.spec/plans/work-queue.md)를 교차 분류했다. 기능별 하위 필드/화면 요소/공통 gate는 각 정본이 소유하며 [완료 감사](completion-audit.md)에서 이 표와 새 통합 계약의 대응을 대조한다. 전수 구현·실행·시각 인수 표가 아니다.

관측 구분: **소스**=직접 source/dispatch 읽기, **상속**=최종 담당 감사/기존 검증 인용, **계약**=요구·계획만 확인. 소스 경로는 조사 진입점이고 전체 지원을 뜻하지 않는다. 모든 행의 새 호스트 제품 실행은 미검증이다. 공통 인수는 [공백](gaps.md)의 G04~G06에 연결하며 N/A는 이유를 기록해야 한다.

## 하위 계약 연결 기준

명령별 상태와 화면별 세부는 각 소유 정본에 유지한다. 이 표는 안정 ID로 연결하며 동일 정책을 복제하지 않는다. 각 행의 구현 세부 확인 수준은 evidence 문서의 조사 범위를 따른다. 특히 media/AI/제작의 ‘미확인’은 부재 판정이 아니며 기존 executor와 host wiring을 먼저 읽는다.
