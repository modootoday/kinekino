## 목표·권한

공통 Rust SDK/CLI의 실제 지원·오류·취소·저장·provenance 검증을 우선한다. 현재 PM 배정은 기존 `tests/jobs/same_endpoint.rs::actual_three_categories_to_owned_playback_on_one_endpoint` 실행 준비다. 같은 PlaybackWorkspaceHost/PlayerSdk/LocalHost에서 airing→completed→movies의 신규 catalog/episodes/resolve→재생 진행/PNG→close 및 EOF 정리를 검증한다. 새 provider/CLI/harness를 만들지 않는다.

최신 AGENTS.md의 공개 디렉터리 경계, Rust·SRP·계층 분리, SDK/CLI 선행, 중앙 root index 소유권을 적용한다. protocol r2/S35·native 배포 closure는 동결한다. SDK P1b/UI/Meari 파일을 수정하지 않는다. 현재 heavy는 SDK union9에 배정되어 있다. 중앙의 별도 배정 전 네트워크·Cargo·실행·신규 추론·다운로드·worker 빌드0을 유지한다.

goal 도구 관측: get_goal은 과거 companion 본문의 active 목표를 반환했고 create_goal은 unfinished goal 존재로 거절됐다. 이 문서가 새 작업 정의이며 도구 목표 재생성 성공으로 표시하지 않는다. 기존 미완료 목표를 가짜 complete 처리하거나 내부 DB를 수정하지 않는다. PM에게 이 불일치와 새 정의를 전달했다.

PM은 역할을 승인했다. 전체 범위는 미디어·AI 제품기능의 Rust SDK/CLI 통합과 원문/출력/취소/저장/재열기·고정 HF 모델/양자화/실측·품질 검토다. 현재 준비→중앙 단일 슬롯 실제 검증→최소 수리→증거·정본화를 우선한다. 모델 사용자 검토는 제품 연결 뒤로 두고 Pages/VM/DPI/장시간 보류와 사용자 앱 보호를 유지한다. 승인 뒤 get_goal 재조회도 과거 active를 반환했으므로 중복 create를 반복하지 않았다.
