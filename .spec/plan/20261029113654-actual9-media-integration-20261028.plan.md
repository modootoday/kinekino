## 확인한 사실

원 패키지 `659b3cb6757259d8e770f6d3c96c4a77dafbab43c6ea540bcc7e0c58e4eb0197`의 실제9는 텍스트 request/candidate/baseline 증거를 보유한다. R67의 선언 컨텍스트는 시간축·미디어 권한이 아니다. 현재 CaseResolver는 exact package/item/source-request를 보유하고 MediaResolver는 그 패키지에 포함된 media asset만 인정한다. 따라서 원9의 request SHA에 임의 경로 또는 caller media hash를 붙이는 방식은 기존 계약을 통과할 수 없다.

로컬 `runtime/ai-spike/source/Sintel.2010.720p.mkv`는681285280bytes, 이번 Get-FileHash 관측 F12C070E295B38CFC94EBD61AC3357C3BAC82D1015985F1E8DA93A4C6496C46D이며 역사 assets-manifest의 source_video SHA와 같다. 파일 존재·내용 동일만 입증하며 실제9의 정확한 source-clock 관계나 재생 admission은 입증하지 않는다. `dialogue.wav`의 역사 구간107~132초는 cue끝133.8초를 포괄하지 않으므로 모든 카드/하이라이트 재생 소스로 자동 선택할 수 없다. 번역 자막은 음성 정답이 아니라는 원 manifest의 한계도 유지한다.
