## 권위와 범위

최신 사용자 지시 → AGENTS → 최종 인계/감사와 terminal receipt → 기능별 현재 계약/선택 소스 → 과거 계획 순으로 충돌을 해소한다. 실제 실행 결과는 해당 source/host/producer 범위에만 귀속한다. FINAL-HANDOFF와 감사5개, supplemental/addendum, PM intake를 인수 근거로 유지한다. 과거 문서의 ‘현재’나 낡은 실행 lease는 새 호스트 실행 허가가 아니다.

## 소유권과 실행

PM: 통합 추적표·결정 충돌·root index·직렬 stage/commit·자원. SDK: application/domain/API/CLI·producer/custody 및 durable 연결. Meari: 독립 submodule·공통 compiler/router/plugin/runtime/assets 계약. Media: actual9 provenance·격리 association/draft 후계. UI: 제품 TSX·Rust 표시/입력·typed adapter·일관성/시안. 이 문서는 담당 소유권을 이전하거나 타 WIP 편집/메시지 발송/새 세션 생성을 승인하지 않는다. 본 goal은 현재 중앙 세션에서 진행한다.

이번 작업은 문서·명시 source 조사와 PM 설계 문서, 외부 의존성 없는 비공개 Rust 문서 링크 보조 도구로 제한했다. 원본 source/preimage/receipt·기존 dirty/untracked·Meari docs2 보존. WARP/추론/다운로드/수동 GUI/Pages/VM/DPI/push 재개0. heavy1/jobs1/conservative2 유지. 캐시 root는 <원 호스트 저장소>/runtime/build-cache이며 문서 도구도 별도 tool namespace를 사용한다. 제품 native/Meari meari-native/runner resource-runner/tmp 문맥은 유지한다.

## 구현 이행

문서가 정한 명령 중 새 association/draft와 viewing preferences/resume은 계획 API이며 제품에 등록되지 않았다. 전체 제작·AI·Meari Q01~Q09 요구는 유지하고 미구현/미검증을 이행 계획에 남긴다. 기존 선택 source375의 실제 stage/전체190·정상 제품 bins와 사용자 GUI는 실행하지 않았다. 설계 goal의 종료가 제품 완료나 보류 해제를 뜻하지 않는다.

## 설계 완료 gate

각 요구사항에 소유 계약·기존 구현과 노출 조건·잔여 계약·성공/오류/취소/저장/복구 인수 기준이 연결되어야 한다. 계획상의 명령 이름을 지원으로 표시하지 않는다. 구현을 막는 미확정 DTO·수명·저장 경계를 해소하거나 명시적 Unsupported/NeedsInput 계약으로 확정한다. 제품 범위를 조용히 제외하거나 사용자 결정을 임의 승인하지 않는다. 미구현/실행 미검증 자체는 설계 미완료와 구별하되 구체 인수 기준이 없으면 설계 공백으로 남긴다.
