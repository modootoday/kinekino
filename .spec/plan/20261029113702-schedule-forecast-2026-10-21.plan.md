# 제품 완성 예상 일정 — 2026-10-21

중앙 PM의 거친 범위 추정이며 담당 확약·실측 속도 기반 완료 예측이 아니다. 기능/실미디어/시각/사용자 품질 승인은 서로 다른 게이트다. 최신 권한은 [실행 배정](execution-leases.md), 근거는 [현재 조율](current-coordination.md), 원래 전체 범위는 [통합 게이트](full-product-integration-gates.md)를 따른다. 아래 날짜를 새 실행·보류 해제 권한으로 사용하지 않는다.

## 현재 근거

- root5040: 공통 SDK/CLI 명시 export 조립 A81+B실NoMedia1 및 UI 단일 video 문서 회귀48을 각각 인수·commit했다. 전체 제품 시험의 누적 분모로 합산하지 않는다.
- UI frame source5·typed owner V2a source3는 독립읽기 인수·실행 전이다. 실제 consumer 설치·기본 Native main·영상/오디오/controls·시각 검토가 남는다.
- 미디어 evidence4 r5는 양 strict/fmt 통과 후 jobs 시험 빌드 중이다. 계획19=순수18+실NoMediaCLI1이며 아직19통과가 아니다.
- SDK 실제 guarded export 시나리오는 source-only 작성 중이다. 현재 빈 목록 시험은 원 seek ACK/landing·응답손실 복구를 입증하지 않는다. 현재 provider는 media-cdn만 허용하며 Frame-host 지원은 별도 확인/계약 대상이다.

## 병렬 흐름과 선행 관계

1. 현재 병렬: SDK 실제 export/종단 시험 작성, UI frame/typed owner 분리, 미디어 evidence 검증. Meari는 필요한 API/소유권 연결을 지원한다.
2. SDK 실제 미디어/3분류 검증과 UI V2b/실OS/main은 코드를 병렬 준비하며 실행 슬롯만 직렬 공유한다. provider 계약과 실제 child/영상 합성이 핵심 불확실성이다.
3. 비AI 제작 executor는 재생 안정화 전체가 끝나기를 기다리지 않고 media/SDK의 독립 패키지에서 구현한다. 공통 저장/job/오류/취소 계약에서 합류한다.
4. AI 입력/출력·검토 UI와 pinned 모델 준비는 제품 계약을 따라 병렬진행한다. 실추론/다운로드는 전체보류해제후 하드웨어예산의 단일worker·단계배정으로재개한다. 모델 품질 검토는 제품 연결 후 마지막에 진행한다.

최우선 경로는 실제 SDK/CLI 미디어 근거→원 Native child/owner 조립→기본 Native 실행→영상/오디오·controls/회차 UX 인수다. 모든 제작/AI 기능이 끝나야 플레이어를 처음 사용할 수 있는 구조로 계획하지 않는다. 단계별 통과/실패와 새로운 실제 미디어 근거가 생길 때 이 추정을 다시 산정한다.
