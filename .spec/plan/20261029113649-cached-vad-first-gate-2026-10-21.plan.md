## 구조 인수와 자원·취소 갭

예상 JSON은 outer load_seconds/total_seconds/inputs/outputs/model_sha256/input_sha256/runtime, result.status=inferred·seconds25·frame_seconds0.032·speech_threshold0.5·total_frames782·scores782·speech_frames를 포함한다. 모든 점수는 유한0..1, speech_frames는>=0.5 개수와 일치해야 한다. 원 512sample+64context·state[2,1,128]를 매 chunk 유지하고 마지막 chunk만 패딩한다. 이번 gate는 저장 모델·입력·출력 구조/종료를 확인하며 사람 VAD recall/false-positive·자막·OPED·자동skip 품질 승인이 아니다. 새 Rust 검증 코드나 시험을 이번 준비에서 작성하지 않았다.

중앙 최초 기준은 RAM4GiB 목표/가용RAM16GiB·VRAM3GiB·C12GiB 여유 및 단일worker/CPU2다. outer conservative2는 실제 affinity first_two(기존 mask3)/BelowNormal/Job descendant 적용을 readback한다. 그러나 **현 ORT intra4/inter1과 measure Rayon/OMP/MKL4는 하드코딩**이므로 OS 허용 논리CPU2와 thread2는 다르다. 새 thread2 요구를 충족했다고 표시하지 않는다. 엄격 thread2가 필수면 중앙이 최소 Rust 변경·별도 build 검증을 먼저 배정해야 한다. 환경변수2만 지정해 ORT4를 바꿨다고 주장하지 않는다.

legacy measure는 100ms 간격 원 child+현재 descendant 합산 PrivateUsage/WorkingSetSize의 최대 표본을 저장한다. OS file cache는 비우지 않으며 실제 peak의 상한 보증이 아니다. 4GiB hard cap·GPU VRAM peak를 수집/강제하지 않는다. 짧은 단일 실행은 표본 누락도 명시하고 samples0을 메모리0으로 인수하지 않는다. 초기에 GPU inference0/VRAM2GiB 시험 미배정이다.

legacy measure의 timeout은600초 child.kill/wait이며 cooperative cancellation, 고정 deadline 전파, 남은 descendant 원 identity/Job family empty proof가 없다. outer resource-runner도 affinity/priority Job을 갖지만 kill-on-close가 없고 정상 child wait receipt를 family-empty·취소 성공으로 확대하지 않는다. 따라서 위 명령만으로 **제품 취소 gate 통과를 주장할 수 없다**. 중앙은 정상 단발 측정 허용 여부와 별도로 기존 owned-process crate의 원 Deadline/소유권/취소·family receipt로 추론 어댑터를 연결할 최소 Rust 후속을 배정해야 한다. 원 timeout600을 짧은 협력취소로 재명명하거나 OS kill을 성공으로 덮지 않는다.

실행이 별도 허용되면 원 handle terminal·receipt, worker PID/executable/creation identity, 출력 bytes/SHA·실패/timeout 포함 시작 수1, source/model/input/binary 불변, memory samples/peak 및 residual process 상태를 보존하고 슬롯을 반환한다. 실패나 runtime load 오류면 새 DLL 자동 다운로드·대체 모델·동일 label 재실행은 하지 않는다. RAM/VRAM/반응성 admission이 미달하면 실행 전 대기한다.
