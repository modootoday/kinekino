# 속도·트랙 선택의 공통 SDK 후속

최신 r3는 fmt/strict·전체307pass18ignored/234247ms0·bins1493ms0 및 동일 actual1pass38.96초/runner39963ms0이다. 4초/full PNG 조건을 유지한 filter0 뒤 속도·실제 audio/video disable복원·복원PNG·기존4controls·close/reopen/stale ID/EOF를 통과했다. [정본](../../sots/verification/application/native-options-cli-2026-10-19.md)에 pins/파일/관측/실패 이력을 보존했다. subtitle 양성·청취·장시간·회차 전환·GUI/전체 제품 완성은 별도다. 아래 검사 중/미실행 설명은 이전 checkpoint 기록이다.

현재 [r1 원진단/실제 실패 및 r2 수리](../../sots/verification/application/native-options-cli-2026-10-19.md)를 보존했다. r1 fmt0·strict15332ms0·전체307/18ignored315732ms0·두bin948ms0 뒤 actual은1failed51.69초다. 실제 속도·audio/video disable복원·stale revision 거부 뒤 복원 PNG 게시가4초 deadline에서 거부됐다. r2는 원 픽셀·해상도·deadline을 유지하고 무손실 PNG compression1 및 오류 stage 시각만 추가했으며 fmt0/strict26269ms0 뒤 전체 검사 중이다. 아래 미등록 준비 설명은 이전 구간이다.

검사 입력 동결은 등록 root domain/application/infrastructure/API 및 실제 native harness다. UI의 `src/presentation/web_ui_adapter`는 root presentation/mod.rs에 등록되지 않았고 Meari는 root Cargo exclude다. snapshot에 이 WIP가 포함돼도 컴파일 입력의 전기간 불변 근거로 합치지 않는다. 등록 presentation 소비 범위는 유지한다.

기준은 [native-r3 실제 인수](../../sots/verification/application/native-episode-playback-2026-10-19.md)다. 현재 네 제어·프레임·종료 성공을 set_rate/select_track/다른 회차 성공으로 확대하지 않는다. 다음 heavy는 중앙 교대에 따르며 현재는 등록 입력을 유지하는 저자원 준비다.

1. domain 속도와 트랙 정책을 분리한다. 속도는 유한한0.25–4.0 값으로 검사하며 자동 clamp하지 않는다. 이 범위는 API의 초기 자원·수치 정책이고 UI presets나 모든 속도에서의 품질 승인 근거가 아니다.
2. 트랙 ID는 종류별 ID와 함께 사용한다. 공개 목록은 최대64개이며 id/kind/language/codec/selected/external만 투영한다. raw external-filename·URL·임의 metadata를 통과시키지 않는다. 누락 selected/external은 false로 추정하지 않는다.
3. 트랙 관측 없음과 관측된 빈 목록을 구별한다. 목록 교체는 revision을 증가시키고 malformed/초과/중복 관측은 이전 권한을 무효화한다. 선택은 현재 engine instance와 마지막 관측 revision·종류/ID에 결합한다. 이 검사는 마지막 관측 기준이며 engine 실행 시점의 원자 transaction/완료 보장이 아니다.
4. Rust mpv adapter에서 speed/track-list 및 실제 선택 속성을 관측하고 bounded JSON 메시지로 처리한다. 기존 네 control 포트의 지원 범위를 임의로 넓히지 않고 명시 native 세션에 advanced 기능을 연결한다. set_rate와 select_track의 payload/schema/typed client/capabilities는 같은 application 계약을 사용한다.
5. 다음 SDK 슬롯에서 모듈 등록·fmt/전체 tests/strict Clippy/bin pin 후 실제 회차로1.25배 관측·1.0복원, 관측 audio/video/subtitle 선택/disable/복원·잘못된 종류/ID/revision/종료 instance 거부를 검사한다. 없는 트랙을 만들어 성공화하지 않는다. receipt 접수와 실제 상태 적용·청취·재생 품질을 구별한다.

초기 준비 소스는 `src/domain/playback_options/{mod,rate,tracks}.rs`, `src/application/playback_session/options.rs`, `src/infrastructure/mpv/{track_projection,option_projection,message_reader,options_state}.rs`다. 처음에는 부모에 등록하지 않고 Rustfmt만 확인했다. 현재 등록 이후 strict/type는 통과했으며 추가 domain4·adapter/framing/상태/queue8개 테스트 실행은 전체 검사로 확인 중이다. 기존 native-r3 source/bin과 별도 구간이며 실제 엔진 인수는 아직 없다.

관측 speed는 실제 유한 양수 값을 기록하므로 요청 정책0.25–4.0으로 clamp하지 않는다. aid/vid/sid의 disabled·unresolved(auto)·관측된 ID와 미관측을 구별한다. effective selection 검증은 목록 selected flag가 누락됐을 때 false를 추정하는 방식으로 대체하지 않는다. 마지막 관측과 engine 실제 적용의 시간차를 명시한다.

근거는 [공식 track-list](https://mpv.io/manual/stable/#property-list)와 [track 선택 옵션](https://mpv.io/manual/stable/#track-selection)이다. ID는 같은 종류 내에서만 유일하며 선택 옵션 값과 실제 playback 선택은 다를 수 있다. 공식 계약 확인을 현재 고정 mpv의 실제 관측으로 대체하지 않는다.

rate/tracks 뒤 실제 episode 목록의 previous/next·transition·GUI 이관, 제작·AI 연결 및 기존 전체 goal을 유지한다. 이 문서는 새로운 feature 완료나 UI 시각 승인으로 간주하지 않는다.
