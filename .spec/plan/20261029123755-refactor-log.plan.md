# kinekino 구조 리팩터링 기록

기준: `/workspace/kinekino-redesign.md` §7. 환경: Linux box, toolchain 1.99.1, jobs=1. Windows 빌드/실행은 [미검증] (후속 GitHub Actions 매트릭스).

## 1단계 — Linux 컴파일 복구 (2026-10-29 KST)
- `image`, `tokio`를 `cfg(windows)` 의존에서 공통 의존으로 이동.
- `infrastructure::review_playback_sessions`를 `cfg(windows)`로 격리 (mpv 워커·`owned_process::infrastructure::windows::JobBudget` 사용).
- "중립"으로 분류했던 `review_source`, `model_review`, `timeline_evidence`, `proposals`, `historical_evidence`, `immutable_storage_paths` 게이트 해제를 시도했으나 `std::os::windows`(`share_mode`, `file_attributes`, `creation_flags`, `as_raw_handle`)와 `content_digest` 등에 실제 의존 → 해제 불가, 되돌림. 3단계 이후 platform 포트로 이전 필요.
- 위 모듈에 의존하는 테스트 격리: `tests/review_matroska_input.rs`, `tests/review_media_preparation.rs`(`#![cfg(windows)]`), `assembly/meari/async_proposals` tests 모듈, `review_source/tests.rs` 1개, `async_proposals/tests/policy.rs` 1개.
- Linux에서 게이트로 인한 dead-code 경고: 크레이트 루트(`src/lib.rs`, `src/main.rs`, `src/bin/player-cli.rs`, owned-process, media-vad-worker)에 `cfg_attr(not(windows), allow(...))` 임시 추가 (platform 분리 후 제거).
- 검증(Linux): fmt 통과 / check --workspace --all-targets 통과 / clippy --all-targets -D warnings 통과 / test 실패 8건(아래) / `player-cli --help`, `capabilities` 실제 실행 OK.
- 알려진 Linux 테스트 실패(기존 Windows 경로 가정, 회귀 아님 [추정]): `application::api::tests::unavailable_commands_preserve_malformed_request_validation`, `application::proposals::card_export::tests` 5건("absolute local PNG paths" 판정), `tests/cli_contract::invalid_endpoint_errors_preserve_valid_request_correlation_without_echoing_endpoint`, `tests/sdk_capability_parity::actual_cli_capabilities_...` (exit code 2 vs 3).
