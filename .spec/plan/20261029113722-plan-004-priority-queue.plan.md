# 사용자 지정 후속 순서

최신 지시: 추가 재생 안정성 시험은 일단 보류하고 환경 정리부터 수행한 뒤 기존 우선순위를 따른다. 웹30분/mpv60분 및 반복 전환·DPI 완료 표본은 유지한다. 수정 빌드60분·실제30초 만료·오류 주입 등 추가 시험을 이번 작업에서 임의 재개하지 않는다.

1. 환경 정리 완료: 사용자 직접 apply 후 대상 폴더 부재 확인. [실행 기록](../../sots/verification/environment/sot-017-environment-cleanup.md).
2. 네이티브 기본 UI: 사용자 UI/UX 방향 승인을 받아 실제 Rust 구현을 재개했다. Pages는 동결한다. PotPlayer 기반 프레임·회차·웹 보조 모드·경량 Rust 아이콘을 일관되게 구현하며 새 UI 실측은 별도 기록한다. [병렬 배분](plan-009-parallel-delivery.md)을 따른다.
3. [문서 재배치](plan-005-spec-reorganization.md)는 승인 후 실행했다. 다음 구현의 선행 기준은 [공통 SDK·GUI/CLI](plan-006-sdk-gui-cli.md)다. player.exe/player-cli.exe가 동일 유스케이스를 사용하고 가제는 metadata로 분리한다. UI는 [요소 계약](../../sots/player/presentation/sot-020-ui-contract.md)을 따른다. 기존 비Rust 이관·WebView 주입 최소화 부채는 남아 있다. Pages는 추가 갱신하지 않는다.
4. DPI/반응형 추가 표본, 광고 필터 갱신/롤백·성능, Rust 카탈로그/북마크/이어보기.
5. 제작 공통 계약·작업 큐, 저장·변환·다운로드·스냅샷·수동 제작.
6. 경량 HF 모델 품질/양자화/GPU·재생 경쟁, 자동 제작·피사체·투영 에셋.
7. 런타임·라이선스·배포 준비.

상세 게이트는 [Studio 계획](plan-003-native-studio-expansion.md)을 따른다. 이 목록은 전체 기능 구현 완료 선언이 아니며 한 단계의 결과와 다음 단계의 미구현 상태를 구별한다.
