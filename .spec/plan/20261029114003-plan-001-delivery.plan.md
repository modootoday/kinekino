## 검증 게이트

- G1: 네이티브 URL이 확인되지 않으면 네이티브 지원 완료로 표시하지 않는다. DRM·인증 요구가 발견되면 원본 세션의 정상 재생 범위 안에서 지원 가능 여부를 기록한다.
- G2: 초기 앱이 실행되어도 광고 차단 후 사이트 재생이 별도로 성공해야 호환성 완료다. Codex 브라우저에서의 무차단 재생은 이를 대신하지 않는다.
- G3: 프로세스 시작 성공은 IPC 명령 적용·영상 진행의 증거가 아니다. mpv 응답과 request_id, 상태 이벤트를 수집해 확인한다.
- G4: 요청 수/메모리/CPU/GPU를 3개 분류 동일 표본에서 차단 on/off로 비교한다. 최초 로드·30분 재생·네이티브 전환 후 유휴를 분리하고 엔진/장치/필터 버전을 기록한다. 경량 기준은 측정 전 수치로 확정하지 않는다.
- G5: 마지막 단계에서 `cargo fmt --check`, `cargo test`, `cargo clippy --all-targets -- -D warnings`, Windows 실행 시험 및 문서/구현 차이 검사를 수행한다.

현재 범위는 프로토타입과 정본화이며 후속 단계를 완료로 체크하지 않는다. 큰 UI 기능을 추가하기 전에 단계 3~4의 재생 가능성을 우선 확인한다.

## 현재 검증 기록

2026-10-18: `cargo test` 4건 통과, `cargo clippy --all-targets -- -D warnings` 통과, 문서 9개의 ID·상대 Markdown 링크 검사 통과. `cargo run -- --smoke-test`에서 WebView2 155.0.4283.60 생성, 초기 페이지 로드 완료 및 최종 실행 70개 요청 콜백을 관측했다(이전 실행 71개). 해당 기동 표본의 차단 카운트는 0이므로 실제 광고 차단 효과의 증거로 사용하지 않는다. 첫 8초 비표시 기동에서는 로드 완료가 관측되지 않아, 진단은 창을 표시하고 20초 후 자체 종료하는 방식으로 변경했다. 영상 재생·네이티브 mpv 검증은 미완료이며 mpv.exe는 설치되어 있지 않다.

위 문단은 최초 기동 검증 당시 기록이다. 후속 실제 앱 검증에서는 작업 폴더의 mpv를 준비하고, 외부 iframe 요청 누락·master.txt 감지 누락·3초 조각 재생·상대 탐색 오차를 수정했다. 최신 결과는 [재생 검증 정본](../../sots/verification/playback/sot-005-playback-validation.md)과 그 기계 판독 결과를 따른다. Rust 테스트는 현재 7건이며 fmt·Clippy도 통과했다.

최종 집계: 방영중 웹/네이티브 증가 55.998/35.624초, 종영 49.998/61.144초, 극장판 77.000/66.191초. 모든 표본에서 알려진 광고 슬롯 노출 0, 네이티브 오류 없음, 오디오 2채널을 관측했다. 재생 앱을 종료한 뒤 소유 mpv도 종료되는 것을 확인했다.

## 검증 후 남은 작업

- 다른 회차·서버, 장시간 재생, 인증 쿠키 필수 소스 및 만료 후 재리졸브. 세 표본 통과를 전체 콘텐츠 호환성으로 확대하지 않는다.
- 미디어 응답과 네비게이션에 세션 세대를 부여하여 이전 페이지의 늦은 콜백을 확실히 폐기하기.
- 실제 스피커 청취, 웹 모드의 운영체제 전체화면·모든 단축키·다양한 광고/팝업 패턴 시험.
- 단일 창·진행바 구현 완료. 회차 패널·이전/다음화·전체화면 자동숨김 구현 완료. 이어보기·Rust 카탈로그·고급 컨트롤·DPI 회귀는 후속.
- mpv 바이너리 및 코덱 구성의 배포 라이선스·NOTICE·업데이트 경로. 현재 실행 파일은 검증 작업 폴더에만 있다.
- 앱·브라우저·GPU 프로세스의 장시간 메모리·CPU 측정, 필터 목록 갱신 및 롤백.

## 가상 모니터 검증 환경

사용자가 가상 모니터 드라이버와 필요 시 격리 환경을 지정했다. [격리 검증 계획](plan-002-isolated-dpi-validation.md)에 실제 Windows DPI 매트릭스·반복 전환·연속 재생 절차와 환경 점검을 기록했다. 현재 관리자/VM 접근 부재로 실행 전 상태이며 앱 zoom으로 대체하지 않는다.

## 호스트 내구 검증 진행

추가 완료: [앱 실제 DPI96/144/192 매트릭스](../../sots/verification/display/sot-016-app-dpi-matrix.md)의 웹/mpv 전체화면·자동숨김·복원, 컨트롤·회차 패널 실기. 제품19건/독립 Rust 도구5건 및 fmt·Clippy 통과. 일반 회차를 제외하던 검증 도구의 영화 길이 고정 조건을 수정했다. 고배율 장시간·혼합 모니터 이동·최소 창·반복 배율 크기 복원은 정본의 남은 범위를 따른다.

최종 상태: 웹30분59초/mpv60분28초 연속 표본 통과. 아래 ‘진행 중’은 시험 도중의 이력이다. 수정 빌드60분 회귀는 별도 잔여다. 제품18건/독립 Rust 검증 도구3건 및 각각 fmt·clippy 통과. 최신 결과는 [검증 정본](../../sots/verification/playback/sot-010-host-endurance-validation.md), 확장 범위는 [Studio 계획](plan-003-native-studio-expansion.md)을 따른다.

사용자 지시로 DPI·VM 설치를 보류하고 호스트에서 광고 차단 ON 시험을 수행했다. 완결 네이티브 회차 전환 10회 및 로딩 중 이전/다음 10쌍·일시정지 유지 확인. 사이트 내부 카드 이동에서 주소/목록 동기화 누락을 재현하여 SourceChanged 어댑터로 수정, 실제 카드→회차→웹/mpv 및 이전/다음·취소 확인. 현재 Rust 테스트 18건. 웹 30분/mpv 60분 연속 재생은 진행 중이며 [검증 정본](../../sots/verification/playback/sot-010-host-endurance-validation.md)에 최종 결과를 반영한다.
