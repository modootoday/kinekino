# 최종 normal GUI 일괄 인수

이 문서는 실행 계획이며 완료 보고가 아니다. 중앙 슬롯·exact producer·현재 source pin을 배정받은 뒤 시행한다. SDK/CLI 기능, native lifetime, GUI 표시·입력, 시각 일치, 사용자 AI 품질 승인을 서로 구별한다.

## 선행 조건

최신 기준 보정: SDK294 `8FB1F1D02231BE3BF1C74A89267EF9CC154EBDC3624E9D481C668F9E4EE8B07F`는 CPU88 및 실제 airing/completed/movies/adjacent4와 종료·복원을 통과했다. 이는 새 제품 UX 통합 검증을 대신하지 않는다. 다음 입력은 Meari55 `0CDBADB1…`와 제품55 `3C772940…`를 합친 joint367 `D50BDA1C237A0F88FCDB5B804E87D1499AFA541108C96CE162D4703DA5B33945` 및 별도 계약 음성 시험 후계다. 먼저 Meari 단독 검증·제품 joint fmt/type/strict/실제 factory·수명 회귀를 통과하고 같은 소스 정상 producer를 확인해야 한다. 아래 SA-04~09는 제품55에 작성됐지만 실행·시각 인수 전이며, 기존267r3의 실패를 해결했다고 선계상하지 않는다. DPI·VM·새 장시간 시험은 이 배정에 포함하지 않는다.

공통 SDK/CLI 기능 gate와 native retirement/fresh registration의 joint CPU 검사가 먼저다. 현재 source720AA의27 통과는 신규 retirement/Viewing 후계 검사로 계상하지 않는다. [267r3 GUI](../../sots/verification/presentation/normal-gui-projection267-r3-awaiting-frame-2026-10-25.md)의 AwaitingFrame/Slot(NotVideo)는 미해결 실행 근거다. 해당 실패가 재현되면 동등한 조작을 반복하지 않고 한 번의 정확 오류·소유 carrier·정상 cleanup을 남긴다.

실행 전 exact source manifest/Root·Meari HEAD·fresh Cargo producer22와 binary hash/크기/file identity, argv/roots를 확인한다. 원 소유 PID·creation UTC·window/ref·고유 capture 경로/hash를 기록한다. PM의 주 모니터/default placement 지시를 따르며 DPI/VM/장치를 변경하지 않는다. 가상 모니터는 별도 승인된 구체 recipe가 있을 때만 사용한다. 테스트 창 하나를 소유하고 다른 앱/사용자 player를 조작하지 않는다.

## 시각 비교와 종료

### 소스에서 확인한 구현 미완성 — 관측만으로 닫지 않음

2026-10-25 [공통 프레임·시청 소스 누락 점검](../../sots/verification/presentation/product-style-source-audit-2026-10-25.md)은 현재 후보를 직접 대조한 추가 근거다. SA-01~03은 별도 style4 `20DF2B717837C17E5C56497AA2EDC4047AEFC570E0FABEC29B147F5251888FF1`에 최소 수리 후보를 작성했으며 parser/실행/GUI 미검증이다. 현283 수명 gate에 자동 합성하지 않는다. 다음은 기존 포괄 체크의 반복이 아니라 구현 자체가 빠진 항목이다.

이 항목을 수정하지 않은 후보로 정상 GUI 배정을 수행할 경우에는 선택 소스의 사실과 미완성만 기록한다. 수명·기능 gate 통과나 사용자에게 화면을 보여 준 사실로 전체 시각 일치를 승인하지 않는다.

콜백 배치 CPU 근거는 큐1024건/4MiB와 실제 drain/admission 구현을 구별한다. canonical0844는 전체 pending을 drain해 Native PendingTurn에 보유하며 forwarding.rs의32는 시험 반복 횟수다. 턴당32 제한은 확인되지 않았으므로 인수 항목/지원 보장으로 사용하지 않는다. 별도 private 후계는 exact path/pin을 확인하고 남은 콜백 소유권·후속 turn 전달을 검증한다.

선택된 `.spec/artifacts/design` manifest의 화면/버전/원본 크기를 기록한다. 각 요소를 동일 crop의1:1/2x/4x로 비교하며 전체 창 축소 인상으로 판정하지 않는다. 헤더·최소화/최대화/복원/닫기·toolbar·timeline·inspector·여백·radius·border·icon/hit/focus를 빠뜨리지 않는다. 생성 시안의 오류는 공통 설계 결정으로 분리한다. 과거 egui 이미지 인수를 현재 Meari 인수로 재사용하지 않는다.

실제 cursor, 클릭 hit rect, 키보드 focus, 물리 소리와 전체화면은 관측한 것만 보고한다. 자동화가 청취/장치 관측을 제공하지 않았다면 오디오 품질이나 출력 장치 성공을 추정하지 않는다. 결과의 품질 판정은 사용자가 실제 GUI에서 원본/후보 비교 후 명시적으로 기록한다.

소유 창을 정상 종료하고 PID 부재·원 worker/endpoint/dispatcher/child cleanup을 확인한다. 실패·중단·미지원·미검증·의도적 공통화를 별도로 기록하고 검증 정본을 현재 source pin과 동기화한다. 새 build/relaunch나 실제 자료 쓰기는 다음 중앙 배정 없이 진행하지 않는다.
