# Shared native playback assembly factory — 2026-10-25

Status: active. Source-only proposal at root8ba92768cdb5a0ba32d1d73fb0fabd662664ba11. No implementation, Cargo, GUI or actual execution authorized by this plan. Related existing plans manual-skip-sdk-cli-contract.md, native-segment-skip-observation.md and native-playback-child-assembly.md cover policy/observation/parent cleanup; this narrower composition-root extraction extends them and does not supersede them. No duplicate factory plan was found in the selected plan audit. Filename follows the neighbouring architecture slug-date convention.

## Outcome

One Rust assembly factory constructs the already-verified standalone native host, single shared playback sessions, skip/export registry owner and SDK wiring; player-cli consumes it with unchanged commands/capabilities/result/error/cleanup behavior. CLI acceptance precedes any desktop integration. Later desktop assembly may share its original engine through existing parent binding/router infrastructure; a second engine, policy/guard/result map or a renamed UI callback cannot count as that connection.
