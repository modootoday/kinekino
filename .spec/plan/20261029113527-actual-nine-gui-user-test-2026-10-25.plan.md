## 실제 사용자 시험 순서

2. 원결과 비교 영역에 위 package SHA와 해당 item ID를 명시 입력하고 자료 조회→후보 선택을 누른다. 모델/revision/정밀도/알려진 문제/검토 기준을 확인한 뒤 ‘원 요청과 원문 읽기’, ‘모델 원결과 읽기’를 누른다. 두 내용은 현재 선택한 같은 package/item에서 와야 하며, 제안 목록 선택과 raw package/item 선택은 별도다. UI가 두 선택을 자동으로 같은 것으로 가정하지 않는다. 잘못된 항목·이전 응답이 보이면 시험을 멈추고 원 ID/오류를 기록한다.

4. 수정하려는 경우 실제 원문 목록의 번호를 명시 입력하고 ‘선택한 원문으로 직접 수정하기’를 누른다. cue/document의 원 참조를 유지하는 빈 입력 버퍼이며 모델 원문을 자동 parse/개선한 결과가 아니다. 교정은 교정 내용, 카드는 앞면/뒷면, 하이라이트는 제목/선택 원문 참조만 수정한다. 이 화면에 PTS 입력·자동 영상 구간 생성은 없다. 숨긴 다른 task 필드가 입력·포커스를 받지 않는지 GUI 고유 검토로 별도 확인한다.
