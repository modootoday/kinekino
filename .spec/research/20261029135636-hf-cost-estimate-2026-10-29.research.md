# kinekino HF 클라우드 추론 비용 산정 (2026-10-29 KST 조사)

원칙: 읽기 전용 조회만 수행. 유료 호출·추론·결제 변경 없음. 토큰 값 미기록.

## 1. 결제 등록 상태
| 항목 | 결과 | 근거 |
|---|---|---|
| 계정 cw4196 플랜 | Free (Pro 아님) | 커넥터 hf_whoami |
| 조직 modootoday 역할 | admin | hf_whoami |
| 조직 플랜(Team/Enterprise 여부) | **커넥터로 확인 불가** | OAuth 범위에 billing 읽기 없음 |
| 결제 수단 등록·크레딧 잔액·지출 한도 | **커넥터로 확인 불가, 사용자가 https://huggingface.co/settings/billing (조직은 https://huggingface.co/organizations/modootoday/settings/billing) 에서 확인 필요** | |

공식 문서상 조건:
- Free 사용자는 월 크레딧 없음. Inference Providers를 쓰려면 **크레딧 선구매 필요** ([pricing](https://huggingface.co/docs/inference-providers/pricing)).
- PRO $9/월, $2 월 크레딧. Team $20/월/인, Enterprise $50/월/인, 좌석당 $2 크레딧 ([pricing](https://huggingface.co/pricing)). 크레딧은 Providers·Endpoints·Spaces·Jobs 공용.
- 조직 과금(`X-HF-Bill-To` / `bill_to`)과 조직 지출 한도·제공자 차단은 **Team/Enterprise 조직만** 가능. → modootoday가 Free 조직이면 조직 과금 불가.
- Inference Endpoints는 **활성 구독 + 신용카드 등록** 필요 ([endpoints pricing](https://huggingface.co/docs/inference-endpoints/pricing)).
- HF는 제공자 단가를 마크업 없이 그대로 청구. hf-inference는 "연산시간 × 하드웨어 단가"(예: $0.00012/초 GPU).

## 3. 시나리오 비용 (환율 가정 1 USD = 1,400 KRW)
가정:
- A1 ASR 비용 = 오디오분 × $0.0002 (deepinfra 고정)
- A2 RMBG는 영상 전체 프레임이 아닌 **샘플 프레임**만 처리. 기본 5초당 1장(분당 12장). 1fps도 병기
- A3 SAM2 Endpoint L4 x1 $0.8/h, 처리속도 실시간 1배(**미검증 가정**), 기동(초기화) 5분 과금(문서: 초기화 중에도 과금), 작업 후 유휴 15분 뒤 scale-to-zero(**유휴 시간 설정값 미확인**)

수식: ASR=$0.0002×m, RMBG=$0.018×m×f(f=분당 프레임), SAM2=$0.8×(m/60 + 5/60 + 15/60)×(기동 횟수)

| 시나리오 | ASR | RMBG (분당12장) | RMBG (1fps) | SAM2 Endpoint |
|---|---|---|---|---|
| 10분 영상 1편 | $0.002 (≈3원) | $2.16 (≈3,024원) | $10.80 (≈15,120원) | $0.40 (≈560원) |
| 60분 영상 1편 | $0.012 (≈17원) | $12.96 (≈18,144원) | $64.80 (≈90,720원) | $1.07 (≈1,493원) |
| 월 100시간(6,000분, 100회 기동) | $1.20 (≈1,680원) | $1,296 (≈181만원) | $6,480 (≈907만원) | $80 + 기동·유휴 100×20분×$0.8≈$26.7 = $106.7 (≈15만원) |

해석: ASR은 사실상 무시 가능한 비용. RMBG를 fal-ai 장당 과금으로 영상에 쓰면 비용이 폭증 → 영상 분할은 **SAM2/RMBG를 Endpoint GPU 시간 과금**으로 돌리는 게 유리(같은 L4에서 RMBG 오픈 가중치 실행 시 위 SAM2 열과 유사, 단 RMBG-2.0 비상업 라이선스·접근 승인 조건 확인 필요).

## 4. 로컬 vs 클라우드 손익분기
- ASR: 월 100시간에 $1.2 → 로컬 GPU 전력비보다도 저렴할 수 있음. 손익분기 사실상 없음, 클라우드 선택 시 비용보다 **프라이버시(영상/음성 업로드)**가 결정 요인.
- 분할(Endpoint L4): 월 비용 ≈ $0.8×(처리시간+기동·유휴). 로컬 GPU(예: 기존 보유 GPU) 한계비용은 전력비뿐 → 보유 GPU가 있으면 로컬 우선. 신규 GPU 구매가 P(원) 라면 손익분기 시간 ≈ P / (0.8×1,400원 − 시간당 전력비). 예: 150만원 GPU, 전력비 시간당 100원 → 약 1,470 GPU시간(월 100시간 기준 약 15개월).
- RMBG fal-ai 장당 과금: 월 수천 장 이상이면 Endpoint가 더 저렴(L4 1시간=$0.8 ≈ 44장 가격).

## 5. 콜드 스타트·유휴
- Endpoints는 초기화+실행 상태 모두 분 단위 과금. scale-to-zero 시 유휴 비용 0이나, 재기동 시 콜드 스타트(수 분, **실측 미확인**) 동안 과금·지연.
- scale-to-zero 상태도 쿼터는 "사용"으로 집계, 일시정지(pause)해야 쿼터 해제.
- 권장: 배치를 모아 1회 기동으로 처리, 유휴 타임아웃 최소값, 작업 종료 후 pause.

## 6. 지출 가드 설계 제안
1. 한도: 작업당 기본 $0.50, 월 $5 (설정 가능). 조직이 Team이면 HF 조직 지출 한도도 동일하게 설정(이중 가드). Free면 크레딧 선구매 금액 자체가 상한 역할.
2. 사전 견적: `CostEstimator` 포트 — 입력(오디오분, 샘플 프레임 수, 예상 GPU분+기동 5분+유휴) × 단가표(버전·조회일 포함 TOML, 정기 갱신)로 최소/예상/최대 견적 표시.
3. 승인 흐름: 견적 표시 → 사용자 승인(작업별 opt-in) → 실행 → 실제 청구 추정치 기록 → 누적이 월 한도 80%면 경고, 100%면 차단(재승인 필요). 견적 대비 150% 초과 시 실행 중단.
4. 폴백 금지: 로컬 실패 시 자동 클라우드 전환 없음. Endpoint는 작업 후 자동 pause, 앱 종료 시 실행 중 Endpoint 경고.
5. 기록: 작업 ID·제공자·모델·견적·실측을 로컬 원장에 저장(토큰 미기록). Enterprise면 조직 usage API로 대조 가능(Team 이하는 불가, 수동 확인).
