# 2D·2.5D·3D 투영 에셋 계약

사용자의 ‘2D/3D 투영용 에셋’은 다음 산출물 계층으로 설계한다. 완전한 3D 메시·리깅 생성까지 완료된다는 의미로 확장하지 않으며 그 기능은 별도 연구 게이트다.

| 단계 | 산출물 | 검증 |
|---|---|---|
| 2D | RGBA PNG 피사체/배경 레이어, 흑백/알파 마스크, pivot/bounds/원본 UV/PTS manifest; 필요 시 이미지 시퀀스 | 합성 시 원본과 위치 정렬·투명 가장자리·프레임 순서 |
| 2.5D | RGB+상대 depth(16bit PNG/float 선택), 층별 평면·parallax/카메라 프리셋, 가려짐/빈 배경 표시 | 작은 시점 이동으로 깊이 방향·경계 찢김·홀 확인. 보이지 않던 배경을 관측 사실로 생성하지 않음 |
| 3D 투영 패키지 | 텍스처·알파와 평면/제한된 depth mesh, UV·카메라/투영 행렬·좌표계, GLB 또는 파일 묶음 | Blender 등 대상 도구 import·축/스케일/투영 위치·알파/재질·색공간 round-trip |
| 완전 3D 생성 연구 | unseen 면·토폴로지·리깅·다중 시점 복원 | 단일 프레임으로 정확 복원 보장 불가. 별도 모델·도구·품질 평가 후 승격 |

[Khronos glTF 설명](https://www.khronos.org/gltf/)에 따라 GLB는 메시·재질·텍스처·카메라 등을 전달하는 후보로 적합하다. 커스텀 투영 데이터가 모든 glTF 뷰어에서 바로 동작한다고 가정하지 않는다. projection.json에 행렬 convention(row/column), handedness, 축(up/forward), 단위, near/far, UV 원점, alpha mode, depth 범위/정규화·상대/metric 구분, source PTS/변환 이력을 명시한다. Blender UV Project 문서는 이번 접근 실패로 실제 연동 근거에서 제외했다. Blender import/export는 아직 미검증이다.
