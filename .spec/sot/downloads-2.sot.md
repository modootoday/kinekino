# 영상 다운로드

현재 회차 또는 사용자가 명시적으로 선택한 회차 묶음을 대상으로 한다. 소스/품질/영상·오디오·자막 트랙/컨테이너/출력 폴더와 예상 용량을 먼저 보여준다. `원본 저장`, `컨테이너 변경(리먹스)`, `호환 파일로 변환`을 구분하며 자동으로 열화 변환하지 않는다.

미디어 요청으로 확인한 소스만 사용한다. HTML·blob·임의 확장자를 영상 파일로 저장하지 않는다. URL·쿠키·Referer는 수명 있는 세션 핸들로 취급하고 프로젝트 파일·진단·작업 이력에는 서명 URL이나 쿠키를 저장하지 않는다. 만료 시 정식 재리졸브 후 같은 미디어/트랙인지 확인하고 재개한다. 인증 또는 DRM이 필요한 경우 지원 여부를 표시한다.

HTTP 범위 재개는 서버 Range와 ETag/Last-Modified 등 동일 객체 검증이 되는 경우에만 수행한다. HLS는 완결 VOD 매니페스트·variant·오디오·초기화 세그먼트·순서/불연속 지점을 검사한 뒤 수집·리먹스한다. 라이브/암호화/키 접근이 필요한 스트림은 지원 매트릭스 판정 전 완료로 표시하지 않는다. 중간 파일을 `.part`로 쓰고 트랙/길이/파일 열림 검증 후 최종 이름으로 원자적 확정한다. 원본과 기존 출력 파일을 자동 덮어쓰지 않는다.

파일명은 작품/회차/트랙을 이용하되 Windows 예약 이름·경로 분리자·길이·동명이파일 충돌을 처리한다. 네트워크 재시도는 횟수 제한/지연/취소를 가지며 앱 재시작 복구 시 source handle을 새 세션으로 다시 확인한다.
