# ASR → 검토 가능한 자막

선택한 오디오 트랙/언어/구간→PCM 추출/리샘플링→VAD/청크→ASR→원본 시간축 복원/경계 병합→선택적 정렬→cue 분할→교정 패널. 원본 PTS 오프셋·샘플레이트·청크 겹침을 기록한다. 정렬이 없는 단어 시간을 sLM이 만들어 채우지 않는다. 번역은 인식 언어와 출력 언어를 구분한 별도 작업이다.

ASR 초안과 sLM 교정안은 분리하고 diff/근거/수락·되돌리기를 제공한다. sLM은 맞춤법·문장 부호·줄바꿈·고유명사 사전을 적용하되 원문과 시간을 몰래 덮어쓰지 않는다. 무음 환각·저신뢰·겹친 대사·음악 구간을 검토 대상으로 표시한다. 모델이 신뢰도를 제공하지 않으면 임의 확률을 만들어 표시하지 않는다. 저장은 [자막 변환 계약](../production/sot-012-media-production.md)을 재사용한다.
