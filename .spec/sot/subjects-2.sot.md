# 피사체 인식과 제작 재사용

탐지(box/class)·분할(mask)·추적(track_id/time)·선택 설명을 분리한다. 첫 흐름은 클릭/박스로 피사체 선택→마스크 수정→시간 추적→장면 변화에서 재확인. 단순 분할 모델이 피사체 이름/캐릭터 신원을 안다고 표시하지 않는다. 이름은 사용자가 붙이는 프로젝트 라벨이고 identity 인식은 범위 밖이다.

마스크는 원본 좌표/PTS/회전 기준과 모델 revision을 보유한다. 머리카락·투명 경계·가려짐·빠른 이동·애니메이션 선화는 표본 검증하고 브러시/포함·제외 점으로 수정한다. crop 추천/썸네일 전경/카드뉴스 누끼/투영 레이어가 같은 검토된 에셋을 참조한다. 추적 크롭은 이동 제한·완화·장면 컷 초기화로 급격한 흔들림을 억제하며 원본 선택을 보존한다.
