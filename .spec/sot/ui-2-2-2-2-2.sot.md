# 공용 UI 컴포넌트 정본

[r169 실제 설정 focus 반환](../../../verification/presentation/settings-focus-return-review-2026-10-19.md): 수정 고정EXE760 SEG에서 Escape/닫기X 후 trigger focus와 Tab없는Return재진입을 확인했다. 최초패널내부진입과다른화면/resize는별도잔여다.

설정 drawer는 비모달 보조 패널이다. 열기 trigger는 안정 ID를 가지며 키보드로 열면 패널의 접근 가능한 첫 컨트롤로 진입한다. Escape/닫기 버튼으로 닫으면 존재하고 활성 상태인 trigger로 focus를 반환한다. focus 테두리는 선택/hover와 구별한다. 전체 native caption이나 탐색을 modal trap으로 가두지 않는다. r164 고정 실행의 [r165 실제 관측](../../../verification/presentation/proposal-layout-panel-audit-2026-10-19.md)에서는 초기 진입·반환 지정이 없으므로 미구현으로 남는다. 패널 열림 상태/입력 buffer/본문 스크롤 보존과 별도 검증한다.

SourceMediaCard는 source 표시 title·Artwork·viewport 기반height를 받는 수동 표시 조합이다. 공용 Card의면/테두리/곡률/패딩 위에 Folder SVG20·말줄임제목/전체hover와 MediaPreview::unavailable를 조합한다. 미연결 재생을 활성화하거나 실제source/PTS/출력형식을 만들지 않는다. SAVE가첫소비자이며 selector/ROI 좌표가 필요한 다른 editor는 이번범위에서교체하지 않는다. 실제1440/760·긴제목·Empty와track/panel회귀확인전완료로표시하지 않는다.

DataTable::show_framed는 기존 열 배치·행 선택·키보드 동작을 공유하는 명시적 외형 변형이다. THIN/BORDER 외곽선·CONTROL radius, 외곽과 맞닿는 header/마지막 행 셀의 개별 모서리, 짧은 header 열 구분과 전체 행 모드의 가로 구분선을 조합한다. JOB가 첫 소비자이며 다른 기본 표를 일괄 변경하지 않는다. 데이터/작업 kind/상태를 생성하지 않는다. 실제1440/760와LongLabels/Empty·출력 셀 클릭/Down/Home/End를 검토하기 전 시각 인수로 표시하지 않는다.

BatchSourceTable은 stable ID·제목·범위·optional 후보수/출력·상태 및 thumbnail slot을 받는 공용 읽기 표다. header/body가 같은 Taffy columns를 사용해 전체 폭을 채우고 source 열만 유동으로 둔다. 기존 TABLE_TIME132/TABLE_INDEX48/TABLE_STATUS88/CONTROL32와 고정 합65% 제한, thumbnail64×36·padding8·THIN border/CONTROL radius를 재사용한다. checkbox는 명시 command 연결 전 비활성이며 후보 미상을0으로 치환하지 않는다. 포함 선택·실제 회차 생성·SDK 경로 해석은 표가 소유하지 않는다.

검사기 첫 그룹 제목은 `inspector::heading`으로 표시해 시작 전 구분선/상단 GROUP 여백을 넣지 않는다. 후속 그룹의 `section`은 GROUP 간격과 구분선을 유지한다. 같은 제목 글꼴·하단 FIELD 간격을 공유하며, 첫 그룹의 의미를 화면 조합이 명시한다. CLIP 수동/AI추천/일괄과 FRAME 검사기의 반복 그룹이 첫 소비자다.

MediaPreview::unavailable는 Artwork/aspect/aspect label/height를 받아 전체 폭 VIDEO_SURFACE 프리뷰와 CHROME transport를 조합한다. 원본 표시/cover는 artboard가 소유하고, 공용 control_icon32·MediaRail·시간 monospace·aspect small·padding6/gap8·THIN border/CONTROL radius를 사용한다. 재생 capability가 없으면 Play/seek/Volume/Fullscreen은 비활성과 이유를 제공하고 시간은 미상으로 둔다. AI추천이 첫 소비자이며 SDK 재생 유스케이스를 이 컴포넌트에 넣지 않는다.

TextComparison 라벨 면 후속: Taffy가 계산한 실제 행 rect를 기준으로 고정 label72 전체 폭과 행 전체 높이를 채운다. 글자 크기로 배경면 폭을 결정하지 않는다. 레이아웃은 기존 sidebar grid가 계속 소유하며 배경 shape는 텍스트보다 앞에 예약해 뒤에서 최종 rect로 갱신한다. 원문 첫 행 좌상단/교정안 마지막 행 좌하단만 CONTROL radius를 적용해 외곽 프레임 모서리와 맞춘다. 가로 구분선과 label/본문 세로 구분선은 THIN/BORDER를 공유한다.

TextComparison은 optional 원문/교정안을 두 행 label72와 유동 본문으로 표시한다. FIELD 면·SELECTED label 면·PANEL padding·THIN border·CONTROL radius·body13을 공유한다. 본문은 원문 전체를 줄바꿈하며 공통 Unicode scalar prefix/suffix 사이의 하나의 변경 span을 amber로 강조한다. 여러 변경점 사이의 불변 문자까지 포함할 수 있어 최소 편집 diff라고 주장하지 않는다. 동일 문구/삭제만 있는 변경은 문자 안내로 구분한다. 제안 생성·수락·confidence·변경 이유는 컴포넌트가 만들지 않는다.

SubjectRow는 stable ID·표시 label/detail·현재 문맥 여부와 thumbnail paint slot을 받는 공용 읽기 행이다. PANEL 면·THIN/FOCUS 외곽선·CONTROL radius·INLINE padding·FIELD gap과44×40 thumbnail/32 menu slot을 사용한다. menu는 직접 작성한 MoreVertical SVG와 연결 필요 상태다. label과 detail은 한 줄 폭 제한 및 원문 hover를 공유한다. SDK/domain 타입과 이미지 경로 해석은 컴포넌트에 넣지 않고 OBJ 투영이 소유한다. 선택/이름 편집/메뉴 intent는 아직 제공하지 않는다.

[r135 segmented 실행 검토](../../../verification/presentation/segmented-focus-review-2026-10-19.md)에서 OBJ의 선택과 다른 Tab focus·Enter 활성화, A2D 원본→Right 알파의 별도 내부 링을 확인했다. 다른 크기/비활성 소비자까지 완료로 확대하지 않는다.

Segmented는 선택 상태의 amber 외곽선과 키보드 focus를 분리한다. focus가 있는 enabled 버튼에는 FOCUS 색·THIN 두께·CONTROL radius의 내부 링을 추가하며 inset은 FOCUS 두께의 두 배다. 선택·focus 여부가 버튼 크기나 grid 간격을 바꾸지 않는다. r134에서 선택 stroke와 focus가 구분되지 않은 관측에 대한 수정이며 실제 재검토 전 완료로 표시하지 않는다.

`toolbar::unavailable_strip`은 전체 폭의 PANEL 면·THIN 외곽선·CONTROL radius·INLINE padding 안에 무테 동작을 조합한다. 내부 동작32/SVG20/간격8과 그룹 구분선은 기존 `unavailable_grouped`와 같은 구현을 공유한다. CARD가 strip의 첫 소비자다. 기존 grouped는 버튼별 frame을 유지해 FRAME·CLIP의 시안 차이를 명시적으로 보존한다. 연결되지 않은 명령은 두 변형 모두 비활성과 이유를 유지한다.

[첫 표시 안정화 검토](../../../verification/presentation/layout-first-frame-review-2026-10-18.md)에 패스 상한의 측정 근거·입력 회귀와 r95/r96 실제 탭/시청 검증 범위를 기록한다.

레이아웃 전환은 같은 프레임 안에서 Taffy 측정→재계산이 안정된 결과를 표시해야 한다. 기본2패스에서 SUB 변환 시각 문자열27줄이 재현됐고7패스에서 안정됐다. 공용 layout 호스트 설정은 상한8패스를 사용한다. 이는 항상8회 렌더하거나 무한 repaint하는 규칙이 아니며, 안정된 프레임1패스와 입력 중복 방지를 회귀 검사한다. 새 중첩 구조가 상한을 넘으면 상한을 무조건 늘리지 않고 구조·안정화 근거를 재검토한다.

GPU 제작 캔버스의 scene·viewport·backend 자원 경계는 [렌더링 정본](rendering.md)을 따른다. UI는 현재 Glow이며 GPU 확장이 토큰·공용 컴포넌트의 시각 일치 책임을 대체하지 않는다.

사용자 지시에 따라 shadcn-ui처럼 프로젝트가 소스를 소유하는 조합 가능한 공용 컴포넌트 체계를 적용한다. React/shadcn 패키지를 Rust 제품에 혼합하지 않는다. Tailwind 범주의 [토큰](design-tokens.md)과 egui_taffy Flexbox/Grid 위에서 구성한다.

## 책임 계층

설정 overlay의 위치·높이는 `components::inspector::drawer`가 소유한다. viewport에서 제목줄·하단 큐·PANEL 여백을 제외한 우측300폭 rect를 매 프레임 사용한다. 화면별 Window 크기나 위치를 복제하지 않는다. `inspector::panel`의 본문 스크롤·고정 footer와 조합하며, 열림·Escape·선택 상태는 shell이 유지한다.

A2D도 `inspector::panel`을 사용한다. 본문 최대 높이에서 footer 상수를 빼고 실제 높이가 다른 버튼을 뒤에 붙이는 자체 계산을 두지 않는다. 알파/피벗/경계/출력 옵션은 본문 스크롤, 합성 검증/패키지 저장과 sample 안내는 공용 고정112 footer로 나눈다. 새 실행에서760 서랍과1440 고정 검사기를 확인한다.

[r124/r125 검토](../../../verification/presentation/asset-inspector-panel-review-2026-10-19.md)에서 A2D 서랍 축소를 수정하고1440/760 본문/고정 footer·Escape,760 PROJ/JOB scroll·footer·Escape 범위를 확인했다. 다른 상태·키보드 순회까지 검증한 것으로 확대하지 않는다.

1. `design_tokens`: palette/semantic color·spacing·sizing·type·border·radius·breakpoint 등 값의 정본.
2. `player_theme`: 토큰을 egui style/state에 적용하는 어댑터. 화면별 테마 소유 금지.
3. `components`: Button/Field/Inspector primitives/MediaRail/WindowTitle/SelectionFrame/Checkerboard/DataTable 등 소스 소유 공용 컴포넌트. variant·size·disabled·focus·접근성 이름을 일관 처리한다.
4. `layout`: Taffy styles/leaves. 행·열·그리드·고정/유동 영역을 조합한다.
5. 화면별 view projection: SDK snapshot에서 선택·단위·미상·표시 origin을 투영한다. 현재 A2D `CanvasInspectorView`는 선택 layer의 절대 pixel 좌표를 borrow하며 live 빈 상태에 demo 값을 주입하지 않는다.
6. 화면: 공용 컴포넌트에 typed 데이터와 action을 연결한다. widget 외형·숫자필드·섹션·버튼을 각 화면에서 새로 그리지 않는다. application/domain 정책과 실제 저장/추론은 SDK 공유 경계를 유지한다.

## 이관과 검증

CollectionState는 workspace read의 origin/state와 표시 행을 받아 미연결·미확인·입력 필요·확인된 빈 목록·표시 개수를 구분한다. Live의 Unsupported/Unknown/NeedsInput을 빈 결과0으로 표시하지 않는다. Ready 또는 명시적 DesignSample만 확인된 표시 행 수를 사용한다. MODEL accordion heading과 JOB 빈 목록 안내가 같은 책임을 사용하며 기존 application 상태를 변경하거나 기능을 활성화하지 않는다.

CueComparison은 cue ID/번호/시각/본문/문법을 받는 공용 읽기 목록이다. 번호 rail32·본문13·문법11 monospace·padding12/8, 중성 선택면·amber선2와 focus2를 사용한다. Card::selectable_row는 카드 선택과 같은 ID/입력 구현을 공유하고 행은 외곽 카드 중첩 없이 하단 구분선으로 연결한다. 두 패널이 selected cue ID를 공유하며 각 목록의 클릭·Up/Down/Home/End를 처리한다. 파싱/변환/저장은 컴포넌트가 수행하지 않는다.

DataTable::Appearance는 행 최소 높이·선행 SVG·행 전체 hit/focus 옵션을 소유한다. JOB는48행과 List20을 사용하고 기존 표 소비자는 기본32행/셀 포커스를 유지한다. 전체 행 옵션은 stable row_id로 클릭·키보드 포커스를 관리하며 원문 hover와 시간 monospace를 보존한다. 상태/진행의 의미는 화면의 typed 투영 책임이며 컴포넌트가 임의 상태를 생성하지 않는다.

Button은 optional Icon을 label과 하나의 egui Button에 조합한다. glyph는 공용 SVG20, primary40·border/radius·focus/disabled는 기존 버튼과 같은 책임이다. JOB 전체 시작과 재시도/취소/출력 폴더가 첫 소비자다. 실행 가능 여부는 호출자의 계약이며 아이콘 추가로 활성화하지 않는다. 검사기 동작은 Taffy FlexWrap으로 버튼 전체가 다음 줄로 이동한다.

각 inspector 필드의 입력 역할·typed optional value·미연결 상태는 [컨트롤 계약](inspector-controls.md)을 따른다. label로 UI 종류를 추측하거나 알 수 없는 toggle/scalar를 false/0으로 치환하지 않는다.

기존 icon-button·tab·layer-row·선택 그룹·텍스트 입력·미리보기 toolbar의 공용 API 정리는 계속 필요하다. 현재 전체 egui 위젯 사용처가 공용 API로 이관됐다고 선언하지 않는다. 공용 컴포넌트마다 사용 화면·variant·normal/hover/pressed/focus/selected/disabled·좁은 배치를 검토한다. headless render는 구조/입력 근거이고 실제 시안 대조를 대신하지 않는다.

UI 컴포넌트와 필요한 인터페이스는 현재 UI 세션에서 함께 설계·구현·실제 검증한다. SDK 세션에는 공통 API 경계와 변경 파일 범위를 조율한다. 시각 검증은 소유 가상 모니터에서 진행한다.

# Accordion

`accordion::group`은 기능별 행을 하나의 PANEL 배경·THIN 외곽선·CONTROL radius로 묶는다. ACCORDION_GROUP_ROW48·행 간격0과 수평 구분선을 사용하고 내부 헤더 개별 border/radius/hover 확장을 제거한다. 기본 단독 헤더는32최소 높이를 유지한다. [r121 실제 검토](../../../verification/presentation/model-connected-groups-review-2026-10-19.md)에1440/760·클릭/Space·scroll·drawer/Escape 범위를 기록한다.

헤더 클릭은 같은 header response에 키보드 포커스를 요청한다. focus는 공용 FOCUS 색·FOCUS 두께·CONTROL radius의 내부 외곽선으로 표시하며 native Space/Enter 활성화와 Tab 순서를 유지한다. [r119/r120 실제 검토](../../../verification/presentation/model-group-header-review-2026-10-19.md)에서 클릭 후 Space 무반응을 수정하고 다음 그룹 Tab/Enter를 확인했다.

`components/accordion.rs`는 native CollapsingHeader의 전체 행 클릭·focus·펼침 저장을 유지하는 공용 그룹 헤더다. 명시 ID와 제목·기능 Icon·기본 열림 상태·본문을 받는다. CONTROL32 최소 높이, 기능 SVG20, STATUS_ICON18 chevron, FIELD8 간격을 공유한다. chevron은 공용 SVG를 열림 정도에 따라 회전해 표시한다. 카탈로그 개수나 기능 지원을 생성하지 않는다. MODEL 후보와 기능별 그룹이 첫 소비자이며 실제 그룹 데이터와 header 외형을 구분한다.
