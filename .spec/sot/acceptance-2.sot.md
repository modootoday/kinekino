# 검증 게이트

권한 있는 테스트 미디어로 포맷 왕복/스타일 손실, 한일 다국어, 임베디드·이미지·burn-in 자막, VFR/회전/HDR, 토큰 만료, HLS 불연속, 범위 재개 불일치, 디스크 부족, 파일 충돌, 취소/재시작, 일괄 부분 실패를 시험한다. 숏폼 컷 경계는 프레임, 오디오는 시작/끝과 A/V sync, 최종 길이는 probe와 실제 플레이어로 확인한다. 카드/썸네일은 출력 픽셀/용량/문구 넘침·순서와 실제 플랫폼 수동 업로드로 검증한다. 플랫폼 업로드 검증은 아직 수행하지 않았다.
