# 화면 구성 정본

2026-10-18 전체 선택 시안 재검토에 따른 구현 계약이다. 기능·필드 의미는 각 탭 계약, 시각 배치와 필수 하위 영역은 이 문서, 공통 치수는 [UI 계약](../sot-020-ui-contract.md)과 [필드 규칙](field-rules.md)이 소유한다. 현재 코드의 공통 미리보기·타임라인·표가 이 문서의 대체물이 될 수 없다. [참조 검토 기록](../../../verification/presentation/design-reference-review-2026-10-18.md)은 이미지 관측이며 구현 완료 증거가 아니다.

## 공통 골격과 형태

일반 제작 제목줄은 제품 식별명 뒤 구분선과 스튜디오 문맥을 공통 표시하고 시청 복귀 시 제거한다. 서로 다른 시안 변형의 선택 근거와 r98/r99 실제 확인은 [제목줄 문맥 검토](../../../verification/presentation/studio-title-context-review-2026-10-18.md)에 있다. offline demo 검토 문구와 실제 제품 문맥은 구분한다.

모든 공통 값은 [디자인 토큰 정본](design-tokens.md)을 따른다. 색상·border·radius·여백을 화면별 임의 값으로 중복 정의하지 않는다.

- 제목줄 → 제작 탐색/중앙 작업/검사기 → 접힌 큐 순서다. 제목줄 32, 탐색 180, 검사기 300, 간격 12, 큐 40 논리 단위를 적용한다. 펼친 큐는 별도 목록 영역이며 40 안에 행을 압축하지 않는다.
- 제목과 설명, 하위 탭, 편집 도구, 작업물, 보조 목록 순서로 시각적 계층을 만든다. 탭이 없는 화면에 빈 탭 줄을 만들지 않는다. 제목은 23, 본문 13, 보조 11, Pretendard를 사용한다.
- 탐색 선택은 중성 어두운 면과 왼쪽 amber 표시선, amber 아이콘·문자다. 하위 탭은 amber 밑줄이다. 선택, hover, 키보드 focus, 비활성을 별도로 표현한다. 시안마다 다른 채움/테두리 탭을 혼합하지 않는다.
- 필드·버튼은 얇은 중성 테두리와 작은 둥근 모서리, 충분한 내부 여백을 갖는다. 패널 외곽선, 필드 외곽선, 선택선, focus선을 같은 굵은 사각형으로 통일하지 않는다. 주요 실행만 amber 채움이며 모든 선택을 주요 실행처럼 칠하지 않는다.
- 선형 SVG 아이콘은 동일 viewBox·stroke·끝 모양을 공유한다. 캡션은 42×32 hit 영역 안에 10~12 glyph, 기본 외곽선 없음, 닫기 hover는 적색, 최대화/복원은 다른 도형이다. 콘텐츠 아이콘의 32 hit 영역과 구분한다.
- 슬라이더는 둥근 가는 track·채워진 진행 구간·원형 thumb다. 시간 범위는 두 경계 handle과 구간 채움, 재생 위치는 독립 playhead로 표현한다.
- 검사기는 제목/필드 그룹/설명·경고/실행 순서다. 실행을 본문 필드와 같은 줄에 무작위 삽입하지 않는다. 긴 검사기는 내부 스크롤, 실행·취소는 접근 가능한 하단 영역을 유지한다.

## 상태·크기 계약

설정 서랍은1280미만에서 우측에 배치하며 제목줄32와 하단 큐40 사이의 가용 높이를 사용한다. 바깥 여백은PANEL12, 폭은INSPECTOR300 토큰을 따른다. 작은 기본 floating window 크기 때문에 빈 화면 공간을 남기고 필드를 숨기지 않는다. 검사기 본문은 내부 스크롤, 실행 영역은 하단 고정을 유지한다. viewport 크기 변경 시 위치/크기를 다시 계산하고 설정 닫기/Escape와 선택·본문 스크롤 보존을 검토한다.

[r123 실제 검토](../../../verification/presentation/settings-drawer-sizing-review-2026-10-19.md):980 MODEL Populated/LongLabels,열린 채760전환·내부 scroll·footer·Escape와760 SEG 닫기 버튼을 확인했다. 다른 전체 화면/상태의 서랍 인수는 별도다.

각 하위 화면은 Empty, Populated, LongLabels, NeedsInput 데모를 갖는다. 실행·실패·취소·완료·이전 revision 결과는 application 상태와 연결하며 데모 fixture만으로 기능 완료로 승격하지 않는다. 빈 상태에서도 해당 편집 구조와 필요한 입력 안내를 유지한다. 이미지·파형·레이어가 없다는 이유로 화면 전체를 일반 표로 바꾸지 않는다.

1280 미만 검사기는 설정 서랍, 1180 미만 탐색은 48 rail, 980 미만 병렬 비교·보조 목록은 세로로 재배치한다. crop/scene canvas는 비율을 보존하고 변환·hit 좌표를 동일하게 적용한다. 760×480에서도 캡션·탐색·설정·주요 저장·큐에 접근 가능해야 한다. 각 편집 영역은 필요한 내부 스크롤을 가지며 전역 너비를 늘리지 않는다.

## 데이터와 구현 책임

이미지/소스/시간축/표/검사기/큐/레이어의 typed read model은 application 소유다. 레이어 bounds·pivot은 원본 pixel, 시간은 정수 µs, 선택은 안정 ID다. 확대·pan·focus는 presentation view state다. 카드 문서·crop·깊이 scene·파일 tree·파형·검증 결과처럼 아직 없는 구조는 SDK 세션과 계약을 먼저 정한다. 기존 일반 TableSnapshot에 임의 문자열로 넣어 페이지 구조를 숨기지 않는다.

`egui_taffy 0.14` Flexbox/Grid와 공통 styles/leaves로 shell·toolbar·rail·canvas·list·inspector를 조합한다. 참조 프로젝트의 패키지/구조를 따르되 테마는 본 프로젝트 시안에서 가져온다. SVG는 직접 작성하고 실제 애니메이션 데모 raster는 ImageGen 자산과 provenance를 사용한다. 에이전트 소유 검토용 player는 하나만 실행하고 검토 후 소유 PID·경로를 확인해 에이전트가 직접 종료한다.
