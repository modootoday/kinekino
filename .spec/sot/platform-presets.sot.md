# 근거와 플랫폼 프리셋

2026-10-18 공식 문서를 조회했다. 출처의 규격은 향후 변경될 수 있으므로 버전 있는 프리셋과 조회일로 관리한다.

| 출처 | 확인한 내용 | 설계 반영 |
|---|---|---|
| [YouTube Shorts 도움말](https://support.google.com/youtube/answer/15424877?hl=en) | 현재 정사각/세로, 최대 3분 Shorts 분류. 업로드 시기 조건 존재 | 9:16·30/60초 기본 제안, 최대 180초 프리셋. 길이/비율을 실제 출력으로 검사하며 60초를 서비스 최대라고 고정하지 않음 |
| [YouTube 썸네일 도움말](https://support.google.com/youtube/answer/72431?hl=en) | 현재 일반 영상 16:9/3840×2160, Shorts 9:16/2160×3840 권장, JPG/PNG. 데스크톱 업로드 한도 50MB. 검증 계정의 데스크톱 Studio에서 Shorts 커스텀 썸네일 지원 안내 | 일반/Shorts 썸네일을 구분. 낮은 해상도 원본을 자동 업스케일하지 않고 목표 크기를 선택. ‘Shorts 썸네일 업로드 불가’라는 오래된 가정 제외 |
| [YouTube 게시물 도움말](https://support.google.com/youtube/answer/7124474?co=GENIE.Platform%3DDesktop&hl=en) | 이미지 게시 기능. 검색에 노출된 공식 안내에는 피드 1:1 제안 | 커뮤니티 정사각 프리셋 제안. 전체 본문 재조회가 실패해 최신 이미지 개수/용량 상한은 확정하지 않음 |
| [Instagram 공식 이미지 도움말](https://help.instagram.com/1631821640426723) | 이번 조회에서는 본문 접근 실패 | 1:1·4:5·3:4·9:16은 제작용 제안 프리셋으로만 제공. 현재 플랫폼 지원 비율/캐러셀 최대 장수로 주장하지 않으며 배포 전 공식 규격과 업로드 실기 재검증 |
| [FFmpeg 문서](https://ffmpeg.org/ffmpeg.html) | streamcopy는 재인코딩 없는 복사, 정확 탐색과 키프레임 제약이 다름. 명시한 자막 인코더의 호환을 자동 보장하지 않음 | 원본 보관/리먹스와 정확 구간 렌더를 다른 작업으로 제공. 트랙·형식 사전 검사 |

1080×1920 숏폼·1080×1080 커뮤니티·1080×1350 카드 프리셋은 앱 기본 제안이다. 플랫폼 필수 해상도라는 뜻이 아니다. 권장 크기 프리셋은 별도로 두며 원본 픽셀 수·확대 여부·추정 파일 크기를 보여준다. 플랫폼 UI 안전영역은 조정 가능한 가이드이며 고정된 공식 보장 영역으로 표시하지 않는다.
