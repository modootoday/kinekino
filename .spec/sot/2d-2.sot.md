# 2D 자산 생성의 공통 픽셀 계약

승인 [task 통합 R30](task-integration-contract.md), [A2D 요소](../../presentation/studio/assets-2d.md), [투영 산출물](../analysis/projection-assets.md)을 구현 단위로 연결한다. 이 문서는 프로젝트/SDKCLI/파일 발행·사용자 품질 완료 문서가 아니다. 입력/모델/검토 admission은 Media 및 기존 Review 소유권을 유지한다.

## 변환 순서와 좌표

domain `asset_generation::AssetTransform`은 명시 sRGB 해석·straight/premultiplied 출력 버퍼·mask threshold·원본 픽셀 feather·trim·유리수 scale·정규화 pivot을 가진다. 값 검증은 원본/PTS/검토 입증이 아니다. 공통 frame 픽셀 예산을 source와 output 각각 적용하며 feather radius0~64px, scale의 양수 분자/분모1~16, pivot0~1000000을 현재 명시 한도로 둔다. 리소스 실측 완료를 뜻하지 않는다.

입력은 원본 좌표의 straight RGBA8과 같은 width/height의 A8 mask다. 회전/원본 SHA/관측 clock·PTS·mask revision은 후속 application admission에서 고정하고, 이 kernel은 회전·PTS·검토를 만들어내지 않는다. 정적 PNG에 영상 PTS를 붙이지 않는다.

1. mask 값이 threshold 이하이면0으로 한다. A8 양자화 기준이며 UI의0~1 값과 변환을 명시한다.
2. source pixel 반경의 수평/수직 box feather를 순서대로 적용한다. canvas 바깥은0, 창 크기는항상2r+1, 각 pass는 가장 가까운 A8로 반올림한다. 분할/추론을 수행하지 않는다.
3. Background 요청은 이 처리 mask를255-mask로 반전한다. 원 source alpha와 곱해 A8로 반올림한다. 배경의 가려진 픽셀이나 새 RGB를 생성하지 않는다.
4. 양의 최종 alpha bounds를 exclusive right/bottom으로 구한다. trim=false는 원 canvas를 유지한다. 완전히 투명한 layer는 NeedsInput으로 구별한다.
5. 목표 크기는 bounds 크기×scale을 올림한 정수이며, 실제 좌표 변환은 원 bounds→실제 목표 크기를 사용한다. 원본 UV는 top-left의 정수 분자/원본 width·height 분모로 기록한다. 원 pivot은 trim 후 음수/바깥일 수 있고 재중앙화하거나 clamp하지 않는다. 출력 pivot은 signed decimal numerator/정수 denominator로 정확히 보존한다.
6. 기존 image0.25.10의 Lanczos3를 사용하되 RGB를 sRGB→linear로 바꾸고 alpha와 associate한 상태에서 resample한다. 결과의 overshoot를 alpha 범위에 제한하고 straight RGB로 복원·sRGB 인코딩한다. Premultiplied 버퍼는 마지막 sRGB8 RGB에 최종 alpha를 곱한다. mask 출력은 실제 최종 alpha다. 1x에서도 동일 source alpha/양자화 의미를 유지한다.

PNG 파일에는 straight alpha를 사용한다. Premultiplied 버퍼를 PNG라고 그대로 발행하거나 alpha_mode를 위조하지 않는다. 파일/texture adapter에서 변환 또는 미지원 판정을 명시해야 한다. 현재 실제 PNG 시험은 straight 경로만 검사한다.

## 원 프레임·mask·review 입력

`AssetFrameRequest`는 원 image blob id/revision/SHA·width/height·선언 색·StaticPng 또는 ObservedVideo의 원 source SHA/stream/정수 PTS/공통 SourceClock/회전을 고정한다. PTS는 canonical signed decimal i64이며 JS f64로 반올림하지 않는다. mask pin은 전체 image pin을 포함하고, coverage Gray8/RGBA8 alpha의 명시 encoding과 ImportedUnverified origin을 보존한다. 동일 mask bytes라도 source identity/revision/clock/회전이 다른 요청으로 재바인딩하지 않는다.

미검토 확인은 정확한 mask blob id/revision/SHA에 묶인다. 검토 참조는 별도 `AssetInputAdmission::open_review`에서 authenticated usable user record와 전체 mask binding을 실제 lease로 확인해야 한다. Prepared/RenderedAssetFrame은 원 image/mask/review lease를 보유하는 비직렬화 carrier다. request reviewed=true나 임의 usable bool로 생성할 수 없다. 합성 review port 시험은 이 계약의 negative/positive 확인이며 실제 사용자 승인으로 계상하지 않는다.

native FixedAssetInputs는 신뢰한 host 카탈로그의 고정 pin/path만 선택하고, 실제 파일 SHA·정적 PNG CRC/완전한 stream·크기·sample encoding을 검사한다. 원 파일/ancestor guard는 원 카탈로그를 해제해도 prepared/rendered carrier에 남는다. PNG RGB tRNS는 RGBA로 확장하며 source alpha를 무시하지 않는다. grayscale coverage와 RGBA alpha는 자동 추측하지 않는다.16bit 입력은 현재 Unsupported로 구별하고8bit로 조용히 축소하지 않는다.

현재 native adapter는 static PNG만 입증한다. ObservedVideo 원 frame-observation resolver 및 실제 authenticated mask review resolver는 미구현이므로 Unsupported다. 영상/모델 관측이나 사용자 승인을 카탈로그 JSON으로 대체하지 않는다. model origin의 추론/모델 pin은 후속 Media 연동 범위에 남는다.

색은 untagged PNG의 명시 declared sRGB 또는 PNG sRGB tag를 소비한다. [PNG 규격](https://www.w3.org/TR/png-3/)의 sRGB 우선순위를 따르며, 알려지지 않은 ICC/cICP와 sRGB tag 없는 gAMA/cHRM은 명시 변환 없이 재해석하지 않는다. 이는 원본 색 품질 실측을 뜻하지 않는다. Mask alpha/coverage는 색 감마가 아닌 지정된 coverage sample로 읽는다. application은 raster의 geometry·buffer 크기·alpha/mask 정합·premultiplied 한도를 재검사하며 원 input carrier를 결과까지 유지한다.

## 취소·수명·산출물

`infrastructure::asset_raster`는 원본 slice를 읽고 새 버퍼만 만든다. mask/feather/좌표/변환/출력의 행 또는 열마다 공통 MutationControl checkpoint를 유지한다. 기존 Lanczos library call 내부에는 취소 hook이 없으므로 반환 후 checkpoint 전까지 임시 결과를 밖으로 반환/발행하지 않는다. 즉시 선점 취소라고 표시하지 않는다. 최초 ApiError의 code/message/details를 그대로 전달한다. 파일·모델·프로세스·publication authority는 이 kernel에 없다.

후속 application은 source/PNG/mask/review 원 lease와 revision을 고정하고 원 Jobs/Core 단일 publication을 재사용해야 한다. 미검토 mask는 특정 mask SHA에 대한 명시 입력 확인과 경고를 보존하며 사용자 AI 품질 승인으로 올리지 않는다. untrusted JSON의 reviewed=true로 검토 gate를 열지 않는다.
