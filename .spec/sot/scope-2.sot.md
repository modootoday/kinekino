# 범위

[네이티브 우선 UX](../../presentation/viewing/sot-011-native-first-studio-ux.md)의 제작 기능 계약이다. 사용자 요청으로 확장한 설계이며 전체 구현·인수는 미완료다. 이용자가 선택한 미디어/로컬 파일과 정상적으로 확인한 재생 소스를 입력으로 한다. 원본 재생 가능 여부가 저장·변환·업로드 가능성을 뜻하지 않는다. 내보내기 결과는 로컬 파일이며 외부 게시·YouTube/Instagram 계정 연결은 별도 후속 범위다.

2026-10-26 소스 대조: download owned executor, snapshot API, accepted proposal의 card/subtitle export와 관련 저장 어댑터 등 부분 구현이 존재한다. 종전 일괄 ‘현재 미구현’을 모든 제작 기능 부재로 해석하지 않는다. 기능별 실제 port/host 주입·지원 조건·기존 증거와 미완료는 [전체 제품 gate](../../../../plans/player/full-product-integration-gates.md) 및 [요구 추적 R25–R31](../../../../plans/player/design-completion/requirements.md)에서 연결한다. 이번 정정은 새 실행 성공이나 전체 기능 지원 판정이 아니다.
