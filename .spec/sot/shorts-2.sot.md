# 숏폼: 수동·추천·일괄 모두

공통 프로젝트는 미디어 ID·입출력 구간·선택 트랙·crop/fit·오디오·자막·출력 프리셋을 보유한다. 수동과 자동 추천을 다른 렌더러로 구현하지 않는다.

1. 수동: 시작/끝 표시→경계 프레임과 길이 확인→세로 크롭/여백→자막/오디오→출력 미리보기→작업 큐.
2. 추천: 장면 변화·음성 구간·자막 의미로 후보 생성→추천 이유/원본 회차·시간 표시→사용자가 수정/선택→동일 프로젝트로 렌더. 추론만으로 원본에 없는 대사·장면을 만들지 않는다.
3. 일괄: 사용자가 회차 묶음·후보 수/길이·중복 제외·공통 템플릿·자원 예산 선택→회차별 후보/출력 요약→명시적 작업 시작. 회차별 실패만 재시도하고 성공 산출물을 중복 생성하지 않는다. 자동 외부 업로드는 포함하지 않는다.

첫 버전은 한 클립 안의 고정 크롭/구간별 조정과 선택 자막을 목표로 한다. 추적 크롭·다중 클립 조합·전환 효과는 후속 단계지만 프로젝트 모델은 구간 배열로 확장 가능하게 한다. 정확 컷/크롭/자막 합성은 재인코딩한다. 빠른 키프레임 컷을 제공할 경우 정확 컷과 이름/경계 차이를 구분한다. 제안 기본은 MP4/H.264/AAC·SDR, 실제 인코더 존재·라이선스·재생 호환 시험 뒤 확정한다.
