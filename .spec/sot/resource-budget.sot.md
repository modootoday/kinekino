# 현재 호스트 관측과 노트북 예산

2026-10-18 08:36 KST 읽기 전용 CIM/nvidia-smi 관측. CPU Intel Core i9-9900KF(8코어/16스레드), 설치 메모리 약 63.93GiB, Windows 11 Pro build 26200, RTX 2070 SUPER 8192MiB 전용 VRAM, NVIDIA 드라이버 610.62. 당시 VRAM 사용 2430MiB/가용 시스템 RAM 약 25.02GiB는 다른 프로그램과 재생 시험을 포함한 순간값이다. [기계 판독 근거](../../../../evidence/ai/ai-host-hardware-2026-10-18.json). CIM AdapterRAM은 약 4GB로 보고되어 8GB 카드 용량 판정에는 nvidia-smi를 사용했다. GPU 부하 시험·설정 변경은 하지 않았다.

사용자 후속 확인: 목표 노트북은 이 데스크톱과 사양이 비슷하므로 **이 호스트를 주 실측 기준으로 사용한다**. 아래 저사양 프로필은 선택 확장 목표로 두며 8GB/16GB 실물 노트북 확보를 현재 작업의 필수 조건으로 삼지 않는다. 아래는 **미측정 설계 예산/인수 목표**이며 보장 사양이 아니다. 재생·OS·다른 프로그램의 메모리는 AI 예산과 별도로 남겨야 한다.

| 프로필 | 목표 환경/실행 | 기본 후보와 제한 | AI 추가 peak 목표 |
|---|---|---|---|
| 절약 | RAM 8GB, 전용 GPU 없음, 4코어급 CPU | tiny 다국어 ASR, 0.6B급 텍스트 모델 Q4 후보/문맥 2K 상한, mobile OCR. 한 모델씩, ASR 청크, 선택 프레임 512px 분리/깊이. 정적 마스크 우선 | 작업 합산 RAM 1.5GiB 이내 목표. 불가 시 입력/모델 축소·시청 중 일시 대기 |
| 균형 | RAM 16GB, CPU/내장 GPU | base ASR, 0.6B~1.7B급 양자화 후보, mobile OCR, 선택적 분리·depth small. 전체 영상은 오프라인 청크 작업 | RAM 3GiB 이내 목표. 전용 VRAM 요구 없음 |
| 고품질 선택 | RAM 16GB 이상, 검증된 전용 GPU | small/0.6B ASR·상위 텍스트·SAM 계열 등 선택 설치 | 사용자 예산과 실제 가용 VRAM 내에서만 실행, 기본값으로 전체 VRAM 점유 금지 |

숫자는 모델 가중치만이 아니라 tokenizer·KV cache·음성/영상 버퍼·런타임·작업 프로세스 전체를 측정한다. 4bit 이름만으로 실행 RAM을 산정하지 않는다. 내장 GPU shared memory도 시스템 RAM 예산에 포함한다. 해상도/청크/문맥을 줄이면 품질 차이를 표시한다. ‘실시간 자동 자막’은 노트북 표본에서 RTF와 지연 기준을 통과하기 전 활성화하지 않고 오프라인 자막 생성을 기본으로 한다.

시청 중 기본은 저부하 모드이며 CPU worker/thread 제한·GPU 추론 배치 축소·무거운 작업 1개·유휴 모델 unload를 지원한다. 배터리에서는 낮은 성능 프리셋을 제안하고 사용자가 바꿀 수 있게 한다. 여러 회차 일괄 작업은 허용하되 동시 병렬 실행을 뜻하지 않는다. 작업별 30초 표본 분석으로 예상 시간/메모리를 측정하는 프리플라이트를 제안하며 자동 대형 모델 설치·다른 앱 종료·전원 설정 변경을 하지 않는다.

주 게이트: 현재 호스트에서 CPU 기준선/RTX 가속과 1080p 재생+ASR/OCR/숏폼 각각의 경쟁을 분리 측정한다. 실제 노트북의 배터리/발열·전력 제한은 동급 사양이어도 차이가 있으므로 미검증으로 남긴다. 전용 GPU 없는 8GB/16GB 실물 노트북은 선택 확장 게이트다. 목표는 UI 입력 응답 p95 100ms 미만·1초 이상 재생 정체 0회·선택 예산 준수다. 디코더 dropped frame 증가/RTF/CER·온도/소비전력은 함께 기록하고 임계값은 기준선 측정 후 조정한다. 현재 호스트의 재생 단독 시험은 AI 경쟁 게이트 완료 증거가 아니다.
