# 2D 에셋

배치·형태·SDK 대응·미구현 차이는 [요소별 시각 계약](assets-2d-visual.md)을 적용한다.

## 시각화

- [레이어와 마스크](../../../../artifacts/design/v2/studio/asset2d.png)

이미지는 배치 참고이며 아래 요소 계약과 공통 필드·상태 규칙이 구현 기준이다.

상태: UI/UX 설계 승인(2026-10-18). 생성 이미지 디테일은 실제 Rust 공통 컴포넌트로 검토한다. 구현 완료와 구분한다. [공통 계약](../sot-020-ui-contract.md)의 프레임·입력 검증·상태·접근성·저장·Rust 계층 규칙을 상속한다. 기본/hover/pressed/selected/disabled/focus는 모든 조작 요소에 적용한다.

## 요소 계약

| 요소 ID | 요소 | 표시와 동작 |
|---|---|---|
| A2D-01 | 입력 | 고정 프레임 또는 검토된 SubjectTrack |
| A2D-02 | 표시 | 원본/알파/합성, checkerboard |
| A2D-03 | 확대 | 원본 pixel 기준 zoom/pan, 좌표 보존 |
| A2D-04 | 마스크 | 포함/제외·브러시·지우개·undo, OBJ와 공통 계약 |
| A2D-05 | 레이어 | 피사체/배경/마스크·숨김·잠금·순서 |
| A2D-06 | 경계 | threshold0~1·feather px, 원본과 비교 |
| A2D-07 | pivot | 중앙/하단/사용자, 정규화 x/y와 원본 px |
| A2D-08 | bounds | 원본/투명 여백 trim, offset 기록 |
| A2D-09 | 크기 | 1x 기본 제안, 확대/축소 표시 |
| A2D-10 | 색/알파 | sRGB·straight/premultiplied 설명과 일관 출력 |
| A2D-11 | 시퀀스 | PTS·순서·누락 프레임, 정적/연속 구분 |
| A2D-12 | 합성 검증 | 원본 배경 위 재합성·정렬 차이 표시 |
| A2D-13 | 출력 | RGBA PNG·mask PNG·manifest JSON 선택 |
| A2D-14 | 저장 | OUT, 미검토 mask는 입력 필요/명시적 승인 |

## 상태와 오류

분할 실패·mask 없음·잘린 경계·원본 재연결을 구별한다. 깊이/진짜 3D 생성 옵션은 이 탭에 섞지 않는다. 배경 생성은 관측 원본과 분리된 후속 작업이다.

## 저장 계약

LayerAsset(source_pts,mask,alpha_mode,pivot,bounds,offset,color), AssetSequence(frames,pts), manifest schema version.

## 인수 기준

가장자리 프린지·알파·원본 재합성·trim offset·pivot·시퀀스 정렬.

각 요소 ID의 유스케이스는 application에, 검증 정책/값 객체는 domain에, OS·추론·파일·프로세스는 infrastructure에 분리한다. presentation은 입력과 렌더링을 담당한다. 모델 미선정/encoder·플랫폼 지원 여부 미확정 항목은 완료로 표시하지 않고 해당 기능을 비활성 또는 NeedsInput으로 제공한다.
