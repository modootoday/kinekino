# 상세 UI와 AI 기능 검토 제안

후속 정본: [UI 계약](../sot-020-ui-contract.md)과 presentation 하위 책임별 문서가 공통 규격·요소·필드·상태의 최신 기준이다. 이 문서는 확장 제안 이력이다. [디자인 자산](../../../../artifacts/design/README.md)은 생성 참고 자료이며 새 화자 탭/SDK/CLI를 시각화한 결과가 아니다.

상태: 사용자 검토 대기. 구현·실측 결과가 아니다. Pages는 사용자 지시로 더 갱신하지 않는다. 이후 결정·변경은 로컬 정본에 기록한다. 문서 재배치 승인은 시안 승인과 구별한다.

## 상세 프레임 규격

치수는 96 DPI 기준의 논리 단위이며 검토 중인 설계값입니다. 이미지의 픽셀 측정보다 이 표를 우선합니다.

| 영역 | 기본 창 1180×760 | 축소 창 760×480 |
|---|---|---|
| 제목 표시줄 | 높이 32, 작품명 말줄임, 창 버튼 우측 고정 | 동일 높이, 보조 아이콘은 메뉴로 |
| 회차 패널 | 너비 260, 경계선 1, 사용자가 열었을 때만 표시 | 강제 자동 닫힘 대신 980 미만 진입 시 임시 접기, 재확대 시 이전 선호 복원 |
| 영상 영역 | 패널 닫힘 1180×672, 열림 920×672 | 패널 접힘 760×392 |
| 탐색선과 조작부 | 합계 높이 56, 탐색선은 조작부 위 전폭 | 주요 재생 버튼과 시간은 유지, 볼륨 슬라이더는 팝오버 |
| 여백과 조작 | 좌우 12, 버튼 간 4~8, 아이콘 18~20 | 라벨 축약보다 보조 기능 메뉴 이동 우선 |

영상 원본 비율은 유지하고 남는 부분은 검정 여백으로 채웁니다. 패널을 여는 동작으로 영상을 강제 확대하거나 자르지 않습니다. 배율 변경 시 창의 작업영역을 먼저 확인하고 화면 밖에 창 버튼이 놓이지 않도록 크기를 제한합니다.

## 재생 컨트롤 상세

| 요소 | 시각 상태와 입력 | 확인할 경계 |
|---|---|---|
| 재생 | 40×40 영역, 재생 중 Pause 아이콘, 일시정지 시 Play | 실제 플레이어 응답 후 상태 확정, 연결 중 클릭 중복 억제 |
| 이전과 다음 | 32×32 영역, 툴팁에 대상 회차 | 첫화·마지막화에서 비활성. 로컬 단일 파일에서는 비활성 |
| 탐색 | 선 두께 3, 포인터/포커스 시 손잡이 10, 입력 영역 높이 16 | 드래그 중 예상 시각 표시, 놓을 때 최종 seek, duration 미상은 비활성 |
| 시간 | 고정폭 숫자 12, 현재 / 전체 | 1시간 이상 HH:MM:SS, 미상 --:--, 서버 대기를 00:00으로 위장하지 않음 |
| 볼륨 | 음소거 아이콘 + 72 길이 슬라이더, 0~100% | 작은 창은 버튼을 눌러 팝오버. 수치와 음소거를 함께 표시 |
| 회차 | 패널이 열리면 선택 배경 + 툴팁 “회차 목록 닫기” | 영상 영역을 덮는 보이지 않는 클릭 레이어 금지 |
| 전체화면 | 진입/종료 아이콘과 툴팁을 상태에 맞춰 교체 | 더블클릭은 영상 배경에서만, 목록·웹·슬라이더 제외 |
| 더보기 | 재생 속도·자막 트랙 등 연결된 기능만 표시 | 미구현 제작·AI 기능을 활성 메뉴처럼 노출하지 않음 |

기본 / hover / pressed / selected / disabled / keyboard-focus의 여섯 상태를 한 세트로 관리합니다. hover는 회색 배경, selected는 옅은 앰버 배경과 표시선, focus는 2단위 외곽선으로 구별합니다. 툴팁은 동작명과 단축키를 함께 보여줍니다.

## 회차 목록 상세

패널 상단은 “회차 목록” 제목과 닫기 버튼, 그 아래 작품명 두 줄과 현재 회차 정보를 둡니다. 행 높이 40, 좌측 두 자리 번호, 가운데 제목, 우측 현재 재생 표시를 사용합니다. 썸네일과 길이는 기본 생략하여 수집 비용과 행 밀도를 줄입니다.

현재 재생 회차와 다음으로 선택한 회차를 분리합니다. 연결 중에는 새 행에 “연결 중” 표시를 두고, 완료되면 현재 재생 표시를 이동합니다. 실패하면 선택 행에 오류 표시와 재시도를 제공하고 이전 회차가 자동 재개되지 않도록 합니다. 연속 클릭은 마지막 선택이 우선입니다.

목록을 열 때 현재 회차를 보이게 하되 사용자가 스크롤 중이면 위치를 강제로 바꾸지 않습니다. 긴 제목은 한 줄 말줄임과 전체 제목 툴팁을 제공합니다. 목록 없음은 “회차 정보가 없습니다”, 로컬 파일은 “이 파일에는 회차 목록이 없습니다”로 구별합니다. 키보드 Up/Down은 선택 이동, Enter는 선택 회차 재생, Esc는 팝오버 닫기부터 처리합니다.

## 로딩과 오류 문구

| 상황 | 문구 | 제공 동작 |
|---|---|---|
| 회차 선택 직후 | “03화를 연결하고 있습니다” | 취소, 다른 회차 선택 |
| 웹 조작 필요 | “재생을 시작하려면 웹 화면에서 확인해 주세요” | 웹 화면 열기 |
| 네이티브 연결 실패 | “영상을 열지 못했습니다”와 짧은 원인 | 다시 시도, 웹으로 재생 |
| 웹 탐색 실패 | “페이지에 연결하지 못했습니다” | 다시 불러오기, 플레이어로 돌아가기 |
| 회차 경계 | “마지막 회차입니다” | 다음 버튼 비활성, 자동 재시도 없음 |

전환 중 이전 영상은 정지 상태로 유지하고 다음 영상이 준비되기 전까지 두 소리가 겹치지 않게 합니다. 상세 진단은 별도 펼침 영역에 두며 서명 URL·쿠키 같은 민감한 값을 표시하지 않습니다.

## 전체화면과 키보드

전체화면에서는 제목 표시줄과 창 테두리를 숨깁니다. 하단 컨트롤은 영상 위 오버레이이며 검은 배경을 적용해 영상 밝기에 따라 읽기 어려워지지 않게 합니다. 재생 중 2.5초 무입력 후 숨김을 제안하고, 일시정지·연결 중·오류·메뉴 열림·드래그 중에는 유지합니다. 키보드로 조작 중인 포커스도 유지합니다. 포인터 이동과 키 입력으로 즉시 복원하고, 숨긴 컨트롤은 클릭을 먼저 소모하지 않습니다.

Esc는 열린 메뉴 → 회차 패널 → 전체화면 순서로 닫습니다. 플레이어의 Space·좌우 탐색 키는 웹 검색창이나 텍스트 입력 중에는 적용하지 않습니다. 입력 장치가 키보드인지 포인터인지에 따라 포커스 강조를 유지합니다.

## 색상과 아이콘 규격

| 토큰 | 제안값 | 용도 |
|---|---|---|
| canvas | #0B0C0E | 영상 여백 |
| chrome | #191B1F | 제목·재생 조작부 |
| panel | #202329 | 목록·팝오버 |
| text | #ECEEF2 | 주요 글자 |
| secondary | #B4BBC7 | 시간·보조 글자 |
| accent | #E8BC5A | 선택·재생 위치 |
| focus | #F1D18A | 키보드 외곽선 |
| disabled | #686E79 | 사용 불가 요소 |

Phosphor Regular 한 굵기를 우선 후보로 유지합니다. Play/Pause, SkipBack/SkipForward, FolderOpen, MagnifyingGlass, SpeakerHigh/SpeakerSlash, ListNumbers, CornersOut/CornersIn, DotsThree, X, Minus, Square 계열을 대응시킵니다. 정확한 Rust 상수와 버전은 구현 전 확인합니다. 아이콘을 이모지나 시스템 폰트 문자로 대체하지 않습니다.

글꼴은 Windows 한국어 가독성을 우선해 맑은 고딕 계열을 후보로 삼고, 제목 12~13·본문 13·보조 11~12 논리 단위를 제안합니다. 폰트 배포 권한과 시스템 폰트 접근은 별도 확인하며 파일을 임의 번들하지 않습니다.

## 작은 창과 향후 제작 도구

980 미만에서는 회차 패널을 임시 접고, 860 미만에서는 볼륨 슬라이더를 팝오버로 전환합니다. 최소 760에서도 이전·재생·다음·시간·회차·전체화면은 남깁니다. 이 임계값은 텍스트 측정 후 조정할 설계값입니다.

자막 저장·다운로드·스냅샷·숏폼·카드뉴스·AI 에셋은 향후 “제작” 작업 공간으로 진입하도록 계획합니다. 시청 화면에 대형 도구막대를 상시 붙이지 않습니다. 현재 시안에는 실제 연결된 재생 기능을 우선하며 미구현 제작 버튼은 표시하지 않습니다.


색상 계산: chrome #191B1F 대비 text 14.84:1, secondary 8.93:1, accent 9.67:1입니다. 지정한 불투명 sRGB 색의 상대휘도 계산값이며 실제 렌더링·반투명 영역·아이콘 경계의 측정값은 아닙니다.

# AI 시청 보조와 제작 기능 상세

모든 AI 화면은 향후 기능 설계입니다. 구간·제목·시각은 예시이며 분석 결과가 아닙니다. 음악이 들린다는 이유만으로 오프닝·엔딩으로 확정하지 않습니다. 재생은 분석 완료를 기다리지 않으며 AI 기능을 끈 상태에서도 전체 시청과 수동 구간 지정이 가능합니다.

## 오프닝과 엔딩 건너뛰기

| 설정 | 오프닝 | 엔딩 |
|---|---|---|
| 끔 | 구간 버튼·자동 이동 없음 | 구간 버튼·자동 이동 없음 |
| 수동 권장 기본값 | 확인된 구간에서 “오프닝 건너뛰기” 버튼 | 확인된 구간에서 “엔딩 건너뛰기” 버튼 |
| 자동 | 확인된 시작점에서 끝점으로 이동 | 확인된 시작점에서 끝점으로 이동, 다음화 자동 전환은 별도 설정 |
| 자동 일시 해제 | 이번 회차만 건너뛰지 않기 | 이번 회차만 건너뛰지 않기 |

설정은 오프닝과 엔딩을 따로 저장합니다. 작품별 예외를 지원하고, 자동 모드는 처음 사용할 때 사용자가 직접 선택합니다. 음악 감지 후보와 사용자가 확인한 구간을 구별하며, 확신이 낮거나 경계가 불분명한 후보는 자동 스킵에 사용하지 않습니다. 신뢰도 수치는 보정 실측 전 임의의 퍼센트로 표시하지 않습니다.

수동 버튼은 해당 구간에 진입할 때 영상 우측 하단, 재생바 위에 표시합니다. 클릭하면 설정된 끝점으로 한 번 이동하고 “오프닝을 건너뛰었습니다 · 되돌리기”를 5초간 제안합니다. 되돌리면 같은 구간을 즉시 다시 건너뛰지 않습니다. 탐색으로 구간에 재진입한 경우도 사용자의 되돌아보기 의도를 우선합니다.

자동 모드는 시작점 3초 전에 “3초 후 오프닝 건너뛰기 · 이번에는 보기”를 표시하는 안입니다. 알림 도중 일시정지하면 카운트다운도 멈춥니다. 남은 시간이 짧으면 해당 길이만 표시하며 연결 직후 이미 중간 지점일 때는 갑작스러운 자동 seek 대신 수동 버튼을 제공합니다. 타이머·구간 값은 실제 재생 시각에 연결하고 벽시계로만 처리하지 않습니다.

엔딩 끝점 뒤에 다음화 예고·쿠키 영상이 있으면 그 앞까지만 건너뜁니다. 엔딩 스킵과 다음화 재생을 하나의 동작으로 묶지 않습니다. 다음화 자동 재생은 별도 끔/켬 설정이며, 마지막 회차·극장판·회차 미상에서는 전환을 제안하지 않습니다. 웹 호환 모드에서 동일 제어가 불가능하면 자동 동작을 비활성하고 이유를 표시합니다.

## 구간 검토 패널

| 요소 | 표시와 동작 |
|---|---|
| 분석 상태 | 모델 없음 / 대기 / 분석 중 / 후보 있음 / 확인됨 / 실패 / 취소 |
| 근거 | 음악 구간, 반복 오디오·영상, 위치 단서의 사용 여부를 짧게 표시 |
| 구간 카드 | 종류·시작·끝·길이, 후보/사용자 확인 표시, 미리보기·수정·삭제 |
| 수동 편집 | 현재 시각으로 시작/끝 지정, 숫자 입력, 경계 ±1초 조정 |
| 미리보기 | 시작 전 3초부터 끝 후 3초까지 확인, 원래 위치로 복귀 |
| 저장 | 이 회차에 적용. 다른 회차 일괄 적용은 별도 확인 필요 |
| 충돌 | 오프닝·엔딩 겹침, 시작≥끝, 영상 밖 범위는 저장 불가 |

오디오 분석만 있는 경우 “음악 기반 후보”로 표시하고 스킵 확정으로 표현하지 않습니다. 오프닝 앞의 콜드 오픈, 본편 배경음악, 짧아진 오프닝, 변형 엔딩, 회상·예고를 검토 사례로 둡니다. 같은 작품이어도 회차별 파일 지문·길이가 달라지면 과거 구간을 무조건 재사용하지 않습니다. 스트림 URL이 바뀌었다는 이유만으로 다른 회차로 취급하지도 않습니다.

타임라인의 OP/ED 표시는 텍스트·모양과 색을 함께 사용합니다. 탐색선의 전체 재생 진척과 구간 오버레이를 분리하고, 구간이 겹치거나 너무 작을 때 상세 편집 패널에서 조정하도록 합니다. 자막이 표시되는 하단 중앙은 피하고, 스킵 버튼 위치와 자막의 충돌을 검사합니다.

## 기능별 작업 화면과 결과 검토

| 기능 | 입력과 설정 | 결과 검토 | 최종 동작 |
|---|---|---|---|
| 구간 감지 | 오디오·영상, 회차, 분석 범위 | OP/ED 후보·경계 미리보기 | 회차별 저장, 수동/자동 모드 적용 |
| 자막 생성 | 오디오 트랙, 언어, 선택 구간 | 시간순 자막 행, 원음 재생, 문장·시각 수정 | 저장 형식 선택과 내보내기 |
| 자막 변환 | 기존 자막, 원본 형식 | 스타일·타이밍 손실 요약 | 대상 형식으로 저장 |
| 피사체 인식 | 선택 프레임·클립, 대상 선택 | 박스·마스크·시간별 추적, 실패 프레임 | 선택 피사체 에셋 저장 |
| 숏폼 | 구간·화면 비율·자막·피사체 추적 | 9:16 자르기와 안전영역, 컷·자막 타임라인 | 수동 편집 또는 자동 제안 확인 후 출력 |
| 스냅샷·썸네일 | 원본 프레임, 텍스트·자르기 | 원본/편집 미리보기 | 원본 보존과 별도 이미지 저장 |
| 카드뉴스 | 유튜브 커뮤니티·인스타그램 용도, 프레임·요약 | 카드별 문구·출처·순서·넘침 | 선택 카드 또는 전체 저장 |
| 2D 에셋 | 프레임·마스크·레이어 | 경계·알파·레이어 확인 | 투명 이미지와 구성 정보 |
| 3D 투영 에셋 | 여러 프레임·피사체·투영 방식 | 깊이 추정·메시·텍스처 확인 | 형식·좌표계·스케일 선택 후 저장 |

음성 인식은 ASR, 음악·구간 감지는 오디오/영상 분류·반복 검출, 피사체 인식은 비전, 문구 작성은 경량 언어 모델로 책임을 나눕니다. 모든 기능을 하나의 sLM이 처리한다고 표현하지 않습니다. 3D 추정은 보이지 않는 면의 복원 정확도를 보장하지 않으며 투영용 2.5D 결과와 완전한 3D 모델을 분리해 표시합니다.

다운로드·인코딩·형식 변환은 일반 미디어 작업으로 구분하고 AI 모델이 필요할 때만 모델 선택을 요구합니다. 숏폼의 수동 제작, 자동 구간 제안, 피사체 추적 기반 제작은 같은 작업 공간 안의 분리된 진입 방식으로 둡니다. 현재 채팅 기록에서 선택 번호만 남아 정확한 대상이 확인되지 않는 자막 우선 형식은 임의로 확정하지 않고 형식 결정 항목으로 남깁니다.

## AI 제작 작업 공간

시청 창의 “제작” 진입점은 실제 기능이 준비된 뒤 노출합니다. 제작 화면은 왼쪽 작업 종류, 가운데 영상·프레임 미리보기와 타임라인, 오른쪽 현재 작업 설정의 세 영역입니다. 한 번에 한 작업을 편집하고, 관련 없는 옵션은 접습니다. 시청 화면으로 돌아가면 편집 초안을 유지합니다.

오른쪽 패널은 입력 → 설정 → 결과 확인 → 저장 순서로 구성합니다. 생성 결과는 원본과 구별하고, 저장 위치·형식·예상 출력 범위와 덮어쓰기 여부를 최종 확인합니다. 저장·게시를 같은 버튼에 묶지 않으며 유튜브·인스타그램 외부 게시 기능은 별도 범위입니다.

## 모델과 자원 관리

| 구분 | UI 기준 |
|---|---|
| Hugging Face 모델 | 저장소·고정 revision·라이선스·파일 크기·작업 종류 표시 |
| 양자화 | 정밀도와 엔진 호환 여부, 메모리/품질 실측 상태를 함께 표시 |
| 모델 없음 | “모델을 선택해 주세요”, 다운로드 용량 확인 후 사용자 실행 |
| 장치 선택 | 자동 / CPU / 지원 GPU. 미지원 조합은 비활성 + 이유 |
| 절약 모드 | 동시 AI 작업 1개, 재생 중 무거운 작업 일시 보류 제안 |
| 작업 중 | 단계·진행률을 알면 수치, 모르면 불확정 진행 표시. 취소 제공 |
| 자원 부족 | 재생 유지 우선, 작업 중단/낮은 정밀도/CPU 대안을 표시 |
| 개인정보 | 분석 범위·임시 파일·로컬 처리 여부 표시, 업로드는 별도 동의 |
| 모델 정리 | 작업에 사용 중인지 표시, 모델·캐시별 제거와 용량 안내 |

절약 모드는 사용자 앱이나 Terminal·ChatGPT를 종료하지 않습니다. GPU 메모리·RAM 한도, 실시간 음악 감지 지연, ASR 속도, 전력 비용은 후보 모델을 이 호스트에서 측정한 뒤 표시합니다. 모델 다운로드와 GPU 초기화를 앱 시작의 필수 단계로 만들지 않습니다. 다운로드·검증·준비·실행·결과 검토·저장을 구분합니다.
