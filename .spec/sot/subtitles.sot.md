# 자막 저장과 변환

출처를 `외부 텍스트 파일 / 컨테이너 내 트랙 / 이미지 자막 / 영상에 입혀진 글자 / ASR 초안`으로 구분한다. 현재 사이트 표본의 화면 자막이 분리 트랙인지 입혀진 것인지 아직 조사하지 않았으며 추출 가능하다고 가정하지 않는다. 트랙이 없으면 ‘자막 없음’과 OCR/음성인식 경로를 안내한다.

저장 흐름: 트랙·언어 선택→원본 보존 또는 SRT/VTT/ASS→전체/현재 구간→동기화 오프셋 적용 여부→손실 미리보기→파일 저장. UTF-8 기본, 한글/일본어 원문 보존, 명시적 인코딩 선택과 오류 위치 표시. 이미지 자막→텍스트는 OCR 작업을 먼저 거치며 단순 확장자 변경으로 처리하지 않는다.

| 대상 | 보존 목표 | 손실/선택 |
|---|---|---|
| 원본 복사 | 스타일/시간/메타데이터 원문 | 수정 없이 저장 가능한 출처에 한함 |
| SRT | 텍스트·시작/끝 | ASS 위치·도형·노래방·복잡한 스타일, VTT 영역/일부 태그 변환 손실 표시 |
| VTT | cue와 제한된 스타일/화자 정보 | 원문 ASS 기능을 모두 매핑한다고 보장하지 않음 |
| ASS | 시간·텍스트, 가능한 원본 스타일 | 단순 형식에서 없던 스타일은 생성된 템플릿으로 구분 |

내부 cue는 정수 마이크로초 시간과 원문/스타일 참조를 보유한다. 원본 소스와 교정본을 함께 유지한다. 구간 `[in,out)`에 겹치는 cue를 자르고 시작을 0으로 재배치한다. 플레이어용 오프셋을 파일에 적용하는 선택은 별도다. 겹침·빈 cue·음수 시간·마지막 경계·VFR 소스를 검증한다. OCR/ASR 교정은 [AI 계약](../analysis/sot-013-local-ai-projection-assets.md)을 따른다.
