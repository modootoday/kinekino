# OCR → 자막

이미지 트랙 OCR과 영상 burn-in OCR을 구분한다. 영상 OCR은 사용자가 자막 ROI·언어·검사 구간을 선택→글자 변화 탐지/프레임 표본→검출/인식→연속 중복 묶기→시작/끝 후보→교정. 프레임 표본 사이 경계 오차를 표시하고 저신뢰 문구/장면 전환을 확인한다. 화면 자막이 한글이어도 음성이 일본어일 수 있어 ASR/OCR 언어를 자동 동일시하지 않는다. 원본 영상에 입혀진 글자를 OCR로 읽는 것은 해당 픽셀을 제거하는 기능과 다르다.
