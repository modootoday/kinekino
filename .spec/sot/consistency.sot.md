# 일관성 기준과 검토 기록

UI 정본의 최상위 품질 기준이다. 화면별 이미지는 개별 생성된 참고 자산이며 실제 공통 Rust 컴포넌트 렌더 결과가 아니다. 각 이미지의 임의 기본값·아이콘·로고·오타·불일치를 정본으로 채택하지 않는다. 사용자 승인 전에 아래 항목을 확인한다.

## 공통 고정 요소

- 동일한 제목줄·탐색 순서·선택 표시·본문/검사기/큐 배치와 최소 작업영역 규칙.
- 동일한 Phosphor Regular 의미 IconId, 크기18/20, 버튼32/40, 포커스2.
- 구간 감지, 자막, 피사체, 숏폼, 스냅샷, 카드뉴스, 2D 에셋, 3D 투영, 다운로드. 모델 관리와 큐는 시스템 진입점으로 구별.
- 절약 모드는 토글/선택기의 실제 상태를 텍스트로도 표시. 끔처럼 보이는 토글에 켜짐 설명을 붙이지 않음.
- 공통 시간 형식·원본 좌표·미디어 ID·revision·출력 경로·오류 해결·취소 의미.
- 문서·저장·변환·큐 추가·게시를 서로 다른 동작으로 표시. 원본과 AI 초안·교정본 분리.
- 모델 미선정에서 분석 비활성, remote revision 고정, 근거 없는 확률·완료·가용성 표시 금지.

## 이미지에서 별도 확인한 주의점

모델 화면의 “revision 미지정 시 최신 사용” 설명은 채택하지 않는다. revision을 고정하기 전 설치를 시작할 수 없다. Q4는 일괄 권장이 아니라 호환·실측 뒤 선택하는 후보이다. OCR 이미지의 confidence 예시 숫자는 실제 지표가 아니며 실제 모델 점수 의미가 검증되기 전 “검토 필요”로 표시한다.

큐 화면은 큐 진입점만 선택 표시하며 다운로드 탭까지 선택하지 않는다. 영상 저장의 소스·트랙이 미확인인 상태에서 호환 성공 체크를 표시하지 않는다. 2D threshold는 정규화0~1이며 8bit 표현을 사용할 경우 변환 단위를 명시한다. 투영 시점은 초기 제안 -10~10도이며 상대 depth와 geometry 단위를 구별한다.

스냅샷에는 원본 프레임/썸네일 편집만 있으며 임의 생성된 “일괄 저장” 탭은 현재 범위가 아니다. 자막·숏폼·투영의 하위 탭과 실제 선택 강조는 각 전용 화면 계약에 맞춘다. 이미지의 폰트는 가시적 참고다. 배포 UI 글꼴은 사용자 지정 Pretendard이며 [타이포그래피 정본](typography.md)의 버전·라이선스·다국어 확장 계약을 따른다.

## 확인 범위

수정 자산 확인: 모델의 고정 revision과 Q4 후보 설명, OCR의 검토 필요 표시, 큐의 취소됨/입력 필요 표시, 소스 확인 전 호환 성공 제거, 스냅샷의 두 하위 탭, 투영의 상대0~1/geometry 단위/시점 -10~10도/내보내기 비활성, AI 추천 하위 탭 강조를 직접 열어 확인했다. 최신 파일은 artifacts/design/manifest.json의 selected_studio로 선택한다. 큐 세부 진단의 경고 색과 일부 로고/아이콘/예시 데이터·폰트 차이는 최종 공통 컴포넌트 렌더에서 정규화해야 하며 현재 이미지의 pixel-perfect 일치가 아니다.

문서의 공통 값과 탭별 요소 ID·저장·오류 계약을 비교했다. 독립 이미지는 열어 가독성과 주요 배치를 검토한다. 픽셀 단위 동일성·실제 Pages 렌더·Rust 컴포넌트 구현·DPI·키보드/접근성 트리·모델 실행/품질은 이 이미지 검토로 검증되지 않는다. 불일치가 남은 자산은 approved가 아닌 review-required로 둔다.

## 승인 뒤

사용자 결정 반영→공통 컴포넌트/토큰 고정→Rust 화면 구현→동일 fixture의 화면별 캡처→상태·DPI·접근성·링크 검사 순서로 진행한다. .spec 전체 재배치는 별도 승인 후 대응표에 따라 수행한다.
