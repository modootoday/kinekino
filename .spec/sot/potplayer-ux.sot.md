# PotPlayer 참고 UX

## 조사 근거

REF-01: [PotPlayer 공식 글로벌 페이지](https://potplayer.tv/)를 내장 브라우저로 직접 열고 대표 이미지를 관찰했다. 어두운 창, 영상 중심 영역, 하단 진행선, 그 아래 재생·정지·이전/다음·시간 표시, 우측 볼륨/목록/설정 계열 아이콘이 보인다. 이는 웹사이트의 홍보 이미지 관찰이며 설치된 최신 앱을 직접 조작한 결과가 아니다.

REF-02: 같은 공식 페이지에서 하드웨어 가속(DXVA/CUDA/QuickSync), 여러 자막 형식, 장면/챕터 북마크를 소개한다. 세부 동작이나 현재 기본 키는 이 페이지로 확정할 수 없다. 국내 구 안내 주소는 현재 서비스 종료 페이지로 연결되어 근거에서 제외했다. 검색에 나온 비공식 배포 사이트의 기능·다운로드는 공식 출처로 사용하지 않았다.

## 디자인에 반영할 원칙

최신 사용자 확정: 네이티브 기본 영상/조작을 중심으로 하고 웹은 탐색·호환 경로로 제공한다. 저장·제작 기능을 포함한 최신 화면/흐름은 [네이티브 우선 제작 UX](sot-011-native-first-studio-ux.md)를 따른다. 아래 목표/구현 기록과 구별한다.

- 영상이 화면의 중심이다. 재생 화면에는 카탈로그 광고·뉴스·댓글·추천 피드를 넣지 않는다.
- 진행바는 컨트롤 위쪽, 재생과 이동은 왼쪽, 현재/전체 시간은 중앙 인접, 볼륨·모드·목록·설정은 오른쪽에 둔다.
- 회차 목록은 우측 접이식 패널로 제공하고 이전/다음 가능한 회차만 활성화한다.
- 자주 쓰는 기능은 한 번의 클릭/키, 코덱·자막 동기화 등 고급 기능은 메뉴·설정으로 점진 노출한다.
- 어두운 중성 배경, 읽을 수 있는 한글 글꼴, 선택 상태와 포커스를 구분한다. PotPlayer 로고·스킨·아이콘을 복제하지 않는다.

## 목표 레이아웃

```text
┌ 제목·현재회차 ───── 웹/네이티브 모드 ── 차단상태 ┐
│                                               │
│                영상                     회차  │
│                                         목록  │
│                                               │
├──────────── 진행바 / 버퍼 범위 ────────────────┤
│ 재생  정지  이전  다음  현재/전체  볼륨  목록 ⚙ │
└───────────────────────────────────────────────┘
```

카탈로그는 별도 탐색 화면 또는 접이식 패널로 둔다. 기본 창 1180×760, 최소 760×480을 초기 설계값으로 한다. 패널·버튼 크기는 DPI 100/150/200%와 한글 텍스트 폭으로 검증한다. 전체화면에서 컨트롤은 입력 시 나타나고 일정 시간 뒤 숨긴다. 키보드 포커스가 텍스트 입력에 있으면 재생 단축키를 가로채지 않는다.

## 제안 키맵 — PotPlayer 기본값이라는 주장이 아님

| 입력 | 앱 목표 동작 |
|---|---|
| Space | 재생/일시정지 |
| Left/Right | -5/+5초 |
| Ctrl+Left/Right | -30/+30초 |
| Up/Down | 볼륨 ±5 |
| Enter 또는 영상 더블클릭 | 전체화면 |
| Escape | 전체화면 해제 후 메뉴 닫기 |
| P | 회차 목록 토글 |
| M | 음소거 |

위 표는 목표 전체 키맵이다. 현재 구현은 단일 창 mpv 영상·진행바·시간·볼륨·웹/mpv 전환·앱 전체화면과 Space/좌우/Escape다. 주소 입력 중 단축키는 가로채지 않는다. 나머지 키맵과 맥락 메뉴는 후속이다. 회차 패널과 자동숨김은 아래 갱신을 따른다. 웹 내부 포커스에서는 원본 플레이어가 키를 처리할 수 있다. [실제 통합 검증](../../../verification/presentation/sot-006-integrated-ui-validation.md)에 구현과 관측 범위를 기록했다.

## 상태와 피드백

웹 호환/네이티브 상태를 늘 구분한다. 미디어 후보 감지 시 바로 재생 성공 표시하지 않는다. 요청 차단 수는 작은 상태 배지로 표시하며 시청을 방해하는 토스트를 반복하지 않는다. 오류는 연결, 리졸브, 인증 만료, 디코딩으로 분류하고 사용자가 취할 수 있는 동작을 붙인다. 자막·화질·속도는 엔진이 지원을 보고한 경우에만 활성화한다.

## 회차·자동숨김 구현 갱신

우측 회차 패널·이전/다음화·P 토글 및 전체화면 3초 비활동 컨트롤 숨김을 구현했다. 최신 구현과 실제 관측은 [회차/자동숨김 검증](../../../verification/presentation/sot-007-episode-controls-validation.md)을 따른다. 종전 미구현 문구는 이 기능에 대해 갱신되며, 전체 키맵·자동 다음화·다중 DPI 회귀는 후속이다.
