# UI 타이포그래피 정본

2026-10-18 사용자 지정: GUI 기본 글꼴은 **Pretendard**다. 시각 설계의 기준은 승인 이미지이며 참조 프로젝트의 테마를 옮기지 않는다.

- 배포본: 공식 Pretendard v1.3.9, 수정하지 않은 static TTF Regular(400)와 SemiBold(600).
- 본문·버튼·입력·탭은 Regular, 화면 제목은 SemiBold. 글꼴 등록은 `src/presentation/typography.rs` 한 곳에서 수행한다.
- 글꼴은 실행 파일에 포함한다. 사용자 PC의 설치 글꼴이나 런타임 CDN 다운로드에 의존하지 않는다. 배포 시 `assets/fonts/pretendard/LICENSE.txt`의 SIL OFL 1.1 전문을 함께 제공한다.
- 시간·수치의 고정폭 표현은 별도 Monospace 계열을 유지하고 한국어 누락을 Pretendard로 보완한다. 아이콘은 SVG이며 글꼴 기호를 사용하지 않는다.
- 글꼴 크기는 공통 테마 토큰을 따르고 임의 화면별 글꼴 등록을 금지한다.

## 다국어 확장 계약

현재 번들 글꼴 적용과 한국어·라틴 문자 표본 확인은 다국어 지원 완료를 뜻하지 않는다. 번역 키/리소스, 로케일 선택·저장, 복수형·수치·날짜 형식, 문자 조형과 RTL 입력은 후속 작업이다.

새 언어 지원 시 문자권별 글리프 범위를 먼저 확인하고 필요한 OFL 호환 글꼴을 버전 고정·라이선스 동봉 후 명시적 fallback 계열에 추가한다. Pretendard가 모든 언어를 포함한다고 가정하지 않는다. 기본 글꼴 뒤의 egui 기본 fallback은 기호 누락 보완용이며 문자권 지원 보증이 아니다.

긴 번역·파일 경로는 Flexbox의 축소 가능한 본문과 콘텐츠 폭 제어 버튼으로 배치하고 줄바꿈/줄임말 규칙을 적용한다. 고정 폭에 한국어 문자열 길이를 가정하지 않는다. 실제 지원할 언어별 표본으로 제목·탭·폼·대기열과 좁은 화면을 검토한다. 자막·출력 이미지의 콘텐츠 글꼴 설정은 GUI 글꼴 설정과 별도 책임이다.

원본: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9

## 일본어 샘플 관측에 따른 fallback

데모 실기에서 일본어 가나 누락을 발견해 공식 Pretendard JP v1.3.9 Regular TTF를 번들 fallback으로 추가했다. 기본 한국어/라틴은 Pretendard Regular를 유지하고 누락 문자는 JP 뒤의 egui fallback 순으로 확인한다. 제목 계열도 같은 fallback을 공유한다. 일본어 표본의 글리프 존재 검사는 통과했으며 번역·로케일·RTL 지원 완료를 의미하지 않는다. JP 원본 OFL 전문은 assets/fonts/pretendard/LICENSE-JP.txt에 동봉한다.
