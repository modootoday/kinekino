# build-host 빌드 캐시 경로

2026-10-26 사용자 후속 지시로 확정. 이 호스트는 D가 없고 HDD가 아닌 Samsung SSD 980 PRO NVMe다. C 프로젝트의 비공개 runtime/build-cache를 실제 출력 루트로 사용한다. 원 호스트 D 정책을 이 호스트에 강제하거나 가짜 D alias를 만들지 않는다.

제품 target은 native, 독립 Meari workspace는 meari-native, 실행기 bootstrap은 resource-runner로 분리한다. 같은 문맥은 재사용하고 gate마다 새 target을 복제하지 않는다. TMP/TEMP는 tmp다. 기존 해시 없는 Meari 산출물 충돌 관측을 고려해 workspace 간 target 공유를 피한다. compiler flags, incremental, debug symbols, 전역 registry/Rustup은 변경하지 않는다. HDD I/O 전제는 해제하지만 producer 독점·heavy1/jobs1/conservative2는 성능 실측 전 유지한다. build4 source candidate를 자동 승격하지 않는다.

root와 Meari 로컬 Cargo config는 절대 C 경로로 고정한다. runner는 환경을 상속하므로 실행 launcher가 문맥별 CARGO_TARGET_DIR와 TMP/TEMP를 지정하고 명시 --target-dir도 동일하게 맞춘다. manifest-path만으로 다른 workspace config를 읽는다고 가정하지 않는다. 실행 계약은 runtime/coordination/host-migration-build-host/datalab-build-paths.json이다. 역사 recipe와 receipt는 수정하지 않는다.

기존 캐시는 이관 제외됐고 이번 변경 시 runtime/build-cache의 기존 내용은 관측되지 않았다. 삭제/이동/압축 없이 필요한 디렉터리를 새로 준비한다. source375/canonical 미통합, 전체190/정상 bins 미실행은 그대로다. 설정 및 실행기 검사와 제품 검증을 구별한다.
