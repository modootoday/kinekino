### 보강 조사
- 배포 크기: Linux libcef.so 비스트립 1.3-1.4GB → `strip -s` 후 약 241-249MB; 로케일 en-US만 남기면 49MB→0.57MB; 패키지(deb/AppImage) 약 141-255MB (https://github.com/littledivy/laufey/pull/52 , https://git.shork.ch/mirrors/Sable/commit/a280edd7dd…). Windows 크기 미확인. 바이너리는 cef-dll-sys build.rs 또는 `export-cef-dir`가 spotifycdn에서 내려받음 → **사용자 승인 전 다운로드 금지**.
- 라이선스: 배포 시 CEF LICENSE.txt + Chromium credits(about:credits 상당) 서드파티 고지 동봉 필요. 공식 CEF 빌드는 독점 코덱(H.264/AAC) 및 Widevine DRM 미포함으로 알려짐 → 외부 영상 제공자 재생에 치명적일 수 있음(미검증, 핵심 위험).
- Linux 창 임베드: CEF windowed 모드는 X11 부모 창(XID) 지정(`linux-x11` feature); Wayland는 X11/XWayland 경유 또는 OSR(off-screen, accelerated_osr+wgpu)로 egui 텍스처 합성. eframe(glow)과의 통합은 OSR 권장(미검증).
- 기능 대응표: 요청 가로채기 = CEF `ResourceRequestHandler`/CDP `Fetch.requestPaused`; JS 브리지 = CEF `ProcessMessage`+V8 바인딩 / CDP `Runtime.addBinding`·`evaluate`; CDP 원시 호출 = CEF `BrowserHost::execute_dev_tools_method`; 음소거 = `BrowserHost::set_audio_muted`, 재생 감지 = `AudioHandler`; 캡처 = OSR `on_paint` 또는 CDP `Page.captureScreenshot`; 새 창 = `LifeSpanHandler::on_before_popup`; 프로파일 = `RequestContextSettings.cache_path`.

## 결정
`kinekino-browser/src/engine/port/`에 trait `BrowserEngine`, `BrowserEvent`, `NetworkInterceptor`, `AudioControl`, `FrameCapture` 정의. 어댑터 `engine/chromium/cef/`(GUI, 기본), `engine/chromium/cdp/`(CLI/헤드리스), `engine/webview2/`(cfg(windows), 전환 기간 한정 후 제거). OS 종속 cfg는 `kinekino-platform` 파사드에만. 주입 JS 4개는 포트 스크립트 자산으로 유지.

## 이행 계획
0. 승인: CEF 바이너리 다운로드(~수백MB) + 코덱/DRM 요구 확인.
1. 포트 정의 + 계약 테스트(가짜 엔진), 기존 WebView2 코드를 engine/webview2로 이관(동작 불변).
2. CDP 어댑터(chromiumoxide, 시스템 Chromium) → Linux에서 CLI 제공자 접근·요청 차단·eval·스크린샷 통과.
3. cef-rs 스파이크: cefsimple 실행 → OSR로 eframe 창 합성, 가로채기·브리지·음소거.
4. 기능 동등성 표 전 항목 통과 후 GUI 기본 엔진 전환; 번들러(xtask)에 strip/로케일 축소/고지 동봉.
5. Windows: GitHub Actions + build-host 검증 후 webview2 어댑터와 wry/webview2-com 제거, adr-001 superseded.

## 위험·미검증
코덱/DRM 부재(최대 위험), 바이너리 크기·업데이트 주기(Chromium 보안 패치 ~4주마다 크레이트 갱신 추종 필요), CEF 멀티프로세스/샌드박스(Linux chrome-sandbox setuid), Wayland, Windows 크기, 런타임 부트스트랩 코드 부재 여부, OSR 성능. 모두 미실측.

## 개발 장비(Linux 데스크탑) 검증
- CDP: 시스템 chromium을 `--remote-debugging-port=9222 --user-data-dir=/tmp/kk-prof` 로 데스크탑 DISPLAY에 띄우고 chromiumoxide 예제로 navigate/차단/eval/스크린샷.
- CEF(승인 후): `cargo run -p export-cef-dir -- --force ~/.local/share/cef`; `CEF_PATH`, `LD_LIBRARY_PATH` 설정; `cargo run --bin bundle-cef-app -- cefsimple -o target/bundle --release && ./target/bundle/cefsimple` 를 데스크탑에 띄워 사용자 육안 확인.

## Revision 2026-10-29 — codec/DRM requirement (H.264/AAC + Widevine mandatory)

Measured on box (Linux, Google Chrome 156.0.8078.47, CDP via chromiumoxide 0.9.1, local fixture only):

| probe | headless | headed (DISPLAY=:7) |
|---|---|---|
| MSE isTypeSupported avc1.42E01E+mp4a.40.2 | true | true |
| H.264/AAC playback (currentTime>0.3) | true (15 frames) | true (13 frames) |
| EME com.widevine.alpha access + createMediaKeys | ok | ok |
| Fetch interception block / JS inject / PNG capture | ok | ok |

Not verified: actual Widevine license exchange + encrypted playback (requires external licensed service — out of scope), Windows.

### Feature parity
| capability | WebView2 (current) | Chrome+CDP (new default) | CEF official |
|---|---|---|---|
| H.264/AAC | yes | yes (measured) | no (proprietary_codecs off) |
| Widevine | yes | yes, bundled CDM (access measured) | no without Google CDM agreement |
| Network intercept | WebResourceRequested | Fetch domain (measured) | CefResourceRequestHandler |
| Script inject | AddScriptToExecuteOnDocumentCreated | Page.addScriptToEvaluateOnNewDocument (measured) | OnContextCreated |
| Frame capture | CapturePreview | Page.captureScreenshot (measured) | OSR paint |
| Per-page mute | yes | JS on media elements (no CDP API) | SetAudioMuted |
| Embed in app window | yes (child HWND) | no — separate `--app` window | yes (X11 parent / OSR) |
| Ship size | OS runtime | uses installed Chrome (0 MB) | ~250 MB stripped |

### Decision
Default engine = installed Google Chrome over CDP (`KINEKINO_CHROME_PATH`, default /usr/bin/google-chrome). Limitation: no in-window embedding; UX is a separate app window. CEF stays a spike only; adopt only if a licensed-codec build (proprietary_codecs=true, ffmpeg_branding=Chrome — H.264 patent licensing is the distributor's responsibility) AND a Widevine CDM distribution agreement with Google are obtained. Both need a user/legal decision.
