# 플레이어 환경설정 영속

## Context

로드맵 plan:kinekino/20261031153240의 M1-7(PL-7)이다. 볼륨·재생 속도·자동 다음화는 실행마다 기본값(100·1.0·끔)으로 돌아가고, 이어보기 파일(ADR 20261103035240)은 재생 위치만 다룬다. SoT sot:kinekino/viewing-preferences-and-resume의 ViewingPreferences는 volume·muted와 CAS·SDK 표면까지 정의하지만, 이 조각은 로드맵이 적은 세 값(볼륨·속도·자동 다음화)과 그와 붙어 있는 음소거만 실행을 넘어 남기는 첫 경로다. 트랙 선택·선호 언어, pause_intent, 패널, 창 bounds, SDK 표면(viewing.preferences.*)은 범위 밖이다.

## Decision

1. **위치.** `kinekino-core::playback`에 둔다. domain은 `prefs/value.rs`(PlayerPrefs 값과 클램프), application은 `prefs/store.rs`(PlayerPrefsStore 포트·메모리 구현), infrastructure는 `prefs/file/`(파일 저장소·형식·기본 경로)이다. 컨트롤러는 포트를 통해 읽고 쓰며 파일 경로를 모른다.
2. **값.** `volume`(0–100, 정수로 저장), `muted`(bool), `speed`(0.25–4.0, 소수점 두 자리), `auto_next`(bool). 기본값은 현재 View 기본과 같다(100, false, 1.0, false). 읽은 값은 클램프하고, 범위를 벗어난 숫자·잘못된 형은 손상으로 취급한다.
3. **저장 위치.** `KINEKINO_PLAYER_PREFS_FILE`이 있으면 그 경로. 없으면 `$XDG_CONFIG_HOME/kinekino/player-prefs.json`, `$HOME/.config/kinekino/player-prefs.json`, `%APPDATA%\kinekino\player-prefs.json` 순. 이어보기(state)와 달리 사용자 의도 설정이므로 config 범주다. 경로 해석은 환경 조회 함수를 받는 순수 함수다.
4. **형식(JSON v1).** `{"version":1,"volume":80,"muted":false,"speed":1.25,"auto_next":true}`. 알 수 없는 필드는 손상. `version`이 없으면 손상, 1보다 크면 새 버전(읽기는 기본값, 쓰기는 Unsupported로 거절).
5. **원자적 쓰기·손상.** 이어보기와 같다: 프로세스별 임시 파일에 쓰고 fsync 후 rename, 손상 파일은 첫 쓰기 전 `.corrupt`로 보존. 오류 메시지에 설정 내용은 넣지 않고 저장소 경로와 원인만 담는다.
6. **적용·저장 시점.** `with_prefs`로 저장소를 붙일 때 한 번 읽어 View와 엔진(volume·mute·speed)에 적용한다. 볼륨·음소거·속도·자동 다음화가 바뀌면 바로 저장한다. 창 닫기에서도 한 번 더 저장한다(닫기 직전 변경 누락 방지). 스모크 실행은 사용자 설정을 바꾸지 않는다. 저장 실패는 재생을 막지 않고 경고를 한 번만 낸다.
7. **호스트 경계.** 사이트별 용어·플러그인 항목 식별자는 넣지 않는다. 이 파일은 호스트 플레이어의 공통 설정이다.

## Rationale

- 로드맵 M1-7이 명시적으로 볼륨·속도·자동 다음화를 적었고, 음소거는 볼륨 UI와 한 쌍이라 함께 둔다(SoT의 volume·muted 분리와 맞음).
- 기존 `settings.json`(mcp·inference)에 섞지 않는다. 플레이어 UI가 app 설정 모듈에 의존하지 않게 하고, 섹션 검증을 늘리지 않는다.
- 이어보기 어댑터와 같은 손상·버전·원자적 쓰기 규칙을 재사용해 동작을 예측 가능하게 한다.
- CAS·revision·SDK 표면은 SoT 전체 계약이며 M1-5와 같이 첫 조각에서는 생략한다.
- skill: 조회 결과 상위가 ML 재개·에이전트 권한 주제로 이 조각과 무관 → 적용 없음.

## Consequences

- 사용자가 바꾼 볼륨·음소거·속도·자동 다음화가 다음 `kinekino watch`에서 그대로 온다.
- 남은 일: 트랙 선택·선호 언어 영속, pause_intent·패널·창 bounds, SoT CAS/SDK 표면, 설정 창(UI-5)과의 연결, 변경 디바운스(연속 키 입력 시 쓰기 횟수).
