# CLIP 일괄 작업 표의 공용 열 구조 검토

공용 `BatchSourceTable`은 썸네일과 제목을 회차 한 열에 묶고 헤더와 본문이 같은 Taffy 열 규격을 사용한다. 가용 폭을 채우고 제목은 남은 폭에서 말줄임한다. 수치 미연결은 대시, 회차 포함 선택은 비활성으로 유지한다. 예시 장면을 실제 회차로 간주하거나 시안의 임의 후보 수를 복제하지 않는다.

- 1440×900 긴 문구: 한·일·영 혼합 제목이 회차 열 안에서 말줄임되고 나머지 열을 밀어내지 않았다.

## 남은 차이와 미검증

회차 제목은 썸네일 위쪽에 정렬돼 있으며 세로 중앙의 광학적 정렬을 추가 개선해야 한다. 시안의 세로 구분선·상태 배지, 실제 회차 포함 선택, 긴 출력 경로, 980/1180 폭과 전 행 스크롤 검증은 남아 있다. 수동 crop·AI 추천 및 다른 화면의 시각 인수로 확대하지 않는다.

## 상태 배지 후속 — 미검증

상태 열의 단순 Label을 기존 공용 badge::show로 조합하는 소스 변경을 준비했다. ‘검토 전’ 문자열과 unknown 값 의미는 유지한다. r145 SDK 독점 lease 동안 고정 대상 실행 파일을 변경하지 않기 위해 새 빌드·실행 검토는 보류한다. 따라서 r144 관측/검사 통과 결과를 이 배지 변경에 적용하지 않는다. 새 test/clippy/build 및1440/760 실행 검토가 남아 있으며 세로 구분선은 아직 구현 전이다.
