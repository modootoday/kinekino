# 회차 전환 안정성 검증

최상위 규칙은 [AGENTS.md](../../../AGENTS.md)다. 기존 [회차·자동숨김 검증](../presentation/sot-007-episode-controls-validation.md)의 후속 기록이다.

## 수정과 책임 배치

- application의 `EpisodeTransition`이 최신 선택, 원래 재생 모드·일시정지 의도, 정상 페이지 도착, 자동 재생 소비, 취소 및 30초 만료를 관리한다. 완료된 전환은 폐기하여 뒤늦은 오탐 만료를 방지한다.
- application의 `NativePauseIntent`가 mpv 시작 시 일시정지 적용 확인 전까지 요청한 상태를 보존한다. 연결 중 기본 `paused=false`를 사용자 의도로 오인하지 않는다.
- infrastructure의 브라우저 이벤트 어댑터가 문서 세대를 전달하고 비동기 콘텐츠 콜백의 세대를 고정한다. presentation은 오래된 세대의 이벤트를 폐기한다.
- IPC는 실제 메시지 출처 URI와 현재 문서 URI가 일치해야 수락한다. 카탈로그 페이지에서는 미디어 감지를 수락하지 않는다. 원본 회차 페이지가 일치할 때만 정상 바로 보기 버튼을 누른다.

## 실제 Windows 앱 관측

광고 요청 차단을 켠 상태에서 실행했다. 이번 표본은 어떤 암부의 소녀공서의 1·2화다. 세 카테고리 전체 재검증을 이번 변경의 결과로 주장하지 않는다.

| 검증 | 관측 및 판정 |
|---|---|
| 웹/네이티브 전체화면 마우스 복원 | 유휴 숨김 후 검은 여백에서 마우스를 움직여 양쪽 모드 컨트롤 복원 확인. 아래 캡처 참조 |
| 회차 선택 직후 종영 카테고리 이동 | 수정 전 이전 영상 시간이 남는 현상 재현. 출처 검사 추가 후 회차 목록 비움, 시간 0/0, mpv 비활성 및 자동 재진입 없음 확인 |
| 일시정지 후 이전→다음 회차 선택 | 수정 전 연결 중 일시정지 의도가 사라져 최종 회차가 재생되는 현상 재현 |
| 일시정지 의도 수정 후 재시험 | 2화 mpv를 일시정지하고 이전화→다음화를 선택. 최종 2화 mpv가 일시정지 상태로 연결되며 두 관측 사이 시간 0초 유지. 이후 재생 버튼으로 재개 시험 |

전체화면 자동화가 반환하는 16×16 아이콘과 실제 3440×1440 창 캡처를 구분해야 했다. 실제 창 영역을 선택한 뒤 마우스 복원을 확인했으며 이를 앱 결함으로 분류하지 않았다.

## 자동 검증과 한계

`cargo fmt --check`, `cargo test` 17건, `cargo clippy --all-targets -- -D warnings`, `cargo build` 통과. 취소·만료, 최신 회차 선택, 오래된 이벤트 폐기, 비동기 콜백 세대 고정, 시작 일시정지 의도에 회귀 테스트를 추가했다. 30초 만료는 단위 검증이며 실제 네트워크 타임아웃 강제 시험은 남아 있다.

세대는 응답/콘텐츠 콜백 처리 시점에 고정한다. 새 문서 이동 뒤 처음 도착한 응답, 같은 URL 재로드 및 iframe 요청을 원래 요청 시점과 완전히 연결하는 식별자는 아직 없다. 빠른 전환의 광범위 반복·장시간 재생·DPI 매트릭스는 후속이다. 원시 서명 미디어 URL·헤더·본문은 증거 문서에 저장하지 않는다.

최종 로그 집계: 일시정지 표본 12개에서 위치 0.171567초로 동일했고, 수동 재개 후 27.699067초까지 진행했다. 네이티브 오류는 없었다. 정상 종료 후 앱과 소유 mpv 잔존 없음. [기계 판독 결과](../../../evidence/playback/transition-reliability-2026-10-18.json)에 원시 로그 SHA-256과 수치를 기록했다. 문서 14개의 ID·상대 링크 검사 통과.
