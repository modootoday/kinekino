## 후속 처리

원래 candidate 바이트·자동 검사 저장값·패키지·사용자 판정 저장소는 수정하지 않는다. 이 검토는 개발 담당의 내용 감사이며 SDK의 사용자 verdict가 아니다. 읽기 전용 화면과 네이티브 MODEL에서 알려진 오류와 이 문서를 함께 안내한다.

교정의 대소문자 정책, 문장 수·반복·완결성, 본문과 cue 근거의 의미 대응, 이유의 실제 음성/영상 근거, 사람이 고른 독립 하이라이트 기준을 분리해 다음 실험 조건으로 고정해야 한다. 프롬프트 또는 제약 변경은 같은 입력의 새 실행으로 보존하고 기존 결과를 덮어쓰지 않는다. 패키지의 range=null을 cue 안의 시각 문자열만으로 채우지 않는다. 검증된 원본 영상 연결이 없는 텍스트 결과에서 장면·동기화 품질을 주장하지 않는다.
