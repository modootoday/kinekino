# 영상 인식·에셋 검증

2026-10-18, [공통 조건](README.md). 실제 Sintel 110초 1280×544 프레임과 배포 자막을 렌더링한 파생 입력을 사용했다. 자연 번인 자막 및 임의 영상 전체 검증은 아니다.

## OCR와 피사체

한국어 PP-OCR의 넓은 ROI는 공백만 인식했다. 수동으로 좁힌 ROI는 `이칼날에는 어두운 과거가 있다.`를 인식했다. PP-OCRv6는 일본어 좁은 ROI의 `この剣には暗い過去が`를 인식했다. 배포 YAML의 BGR 전처리를 코드에 반영하고 재실행해 같은 문구를 확인했다. 수정 전 RGB 실행은 별도 이력으로 남긴다. BGR 재확인 당시 CPU preflight는 약 43.55%였으므로 성능 비교 표본으로 쓰지 않는다. 텍스트 탐지와 다중 프레임 병합은 미검증이다.

후속 [PP-OCRv6 small detection](ocr-detection.md)의 실제map과 [Rust후처리·자동crop한국어인식](ocr-postprocess.md), [원본크레딧30crop 영어인식](ocr-natural-credits.md)을 실행·보존했다. detector와recognizer는 별도모델이며 제한사례의연결을 전체품질로 승격하지 않는다. 원본후처리수치parity·인간gold/corpus·자연번인·여러frame병합은 남아 있다.

RF-DETR nano는 이 프레임에서 person 1개, score 0.95561, 원본 픽셀 상자 약 [190.41,36.64,859.45,537.85]를 출력했다. 추론 약 0.111초이며 캐릭터 신원 판정·추적 검증을 의미하지 않는다.

MobileSAM의 인물 내부 점과 배경 제외 점 입력에서 피부·손·머리 일부가 선택되고 의상 전체가 빠졌다. 약 4.67초 추론 실행은 성공했으나 완전한 피사체 마스크 품질은 미승인이다. 모델의 예측 IoU는 정답 마스크와 계산한 실제 IoU가 아니다.

## 깊이와 투영

비율을 보존하고 14 배수로 맞춘 518×1218 입력, bicubic/ImageNet 전처리로 Depth Anything V2 small을 각각 3회 비교했다.

| 모델 | 중앙 실행시간, 로드 포함 | 최대 표본 private bytes |
| --- | ---: | ---: |
| FP32 | 1.9566344초 | 401,596,416 |
| Q8 | 2.0681191초 | 594,804,736 |

Q8 파일이 작아도 이번 실행의 메모리 최대는 더 컸다. 16bit 출력은 정규화한 상대 깊이이며 미터 단위 거리와 같지 않다. 초기 정사각 전처리 단발 실행과 섞지 않는다. 초기 두 실행은 출력 파일명이 같아 이미지가 덮어써졌고, 반복 비교는 PID별 파일명으로 수정했다.

마스크를 이진 분리한 foreground/background-visible-only RGBA PNG는 조건부 합성 시 원본 픽셀 복원을 통과했다. glTF 평면 메시·UV·텍스처를 생성하고 gltf-rs로 스키마 파싱을 통과했다.

후속으로 FP32 r3 실제 깊이 이미지를 사용해 64×28 격자(1,792정점·3,402삼각형)의 GLB 높이 필드를 생성했다. 폭 2 임의 단위, Z 변위 0.4 임의 단위이며 상대값의 부호·강도는 예술적 조절값이다. 위치·면적 가중 법선·UV·인덱스·내장 PNG를 gltf-rs reader로 다시 읽어 배열 및 이미지 바이트의 완전 일치를 확인했다. 독립 직교 CPU 래스터라이저가 저장된 GLB를 읽은 미리보기도 생성·직접 확인했다. 그림의 돌출/늘어짐은 단일 깊이 표면의 한계이며 완전한 물체 복원이 아니다.

GLB SHA256 `be5339b1babc46f79774ba6cbb8d35e41f4cf0fcc22571f8b2aae10814a0b795`, 깊이 PNG SHA256 `b7e6e51bc92255291b8dda50b17ef5c739bfbc602ffcf03eed695b1214b1ae9d`. [산출물 기준](../../../artifacts/spikes/2026-10-18/README.md)을 따른다. 출력 워커 약 0.115초였지만 100ms 메모리 표본이 1개라 최대 메모리 보장으로 쓰지 않는다.

배경의 가려진 부분 복원, metric/calibrated mesh, 완전한 3D 형상 재구성, 외부 편집기 import/render 왕복은 아직 수행하지 않았다. 로컬 PATH에서 Blender/Assimp 실행 파일을 찾지 못했고 이번 단계에서 설치하지 않았다. Rust reader+미리보기를 외부 편집기 통과로 표시하지 않는다.
