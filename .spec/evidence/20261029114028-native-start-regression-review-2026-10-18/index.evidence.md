# 일반 player 시작·패널·창 회귀 검토

2026-10-18. r68 빌드를 복사한 r69(PID61996, `runtime/review-runs/ui-native-start-20261018-r69/player.exe`)를 ui-demo 없이 기존 가상 모니터 위치3500,100에서 실행했다. 이번 실행은 소스 없는 시작 상태이며 실제 미디어 재생 검증이 아니다.

## 실제 관측

- 일반1180×760: 중앙 play 표식·제품명·파일 열기/작품 탐색·Ctrl+O 안내, 하단 transport·미상 시간`--:--`·볼륨·회차·전체화면 아이콘을 확인했다. 소스 없는 재생/탐색 버튼은 비활성이다.
- P는 오른쪽 회차 목록과 소스 페이지 안내를 열고 중앙 시작 영역을 남은 폭의 가운데로 옮겼다. Escape는 패널만 닫고 시작 화면을 유지했다.
- 커스텀 최대화 버튼을 실제 클릭해 기존 가상 모니터의 최대화 상태를 확인했다. 캡처 메타데이터3840×2112이며 제목줄과 transport가 유지돼 전체화면과 구분된다.
- 복원 접근성 항목5는 관측됐으나 클릭은 `element 5 has no cached bounds`로 수행되지 않았다. 이어 제목줄 제품명 영역을 더블클릭해1180×760으로 복원했다. 커스텀 복원 glyph의 포인터 클릭 성공을 주장하지 않는다. 복원 직후 한 캡처의 과도기 배치는 다음 fresh state에서 정상 일반 배치로 확인했다.
- 제작 버튼 클릭은1440×900의 일반 SEG로 전환했다. source image/시간 범위 연결 필요·미상 옵션·비활성 동작·진행 중인 변환 없음이 표시됐고 데모 이미지/진행률이 주입되지 않았다. Escape는1180×760 시청 시작 화면으로 복귀했다.

소유 r69 창 닫기 버튼으로 종료한 뒤 player.exe/mpv.exe 조회 결과는 비어 있었다. VM·DPI·모니터 구성은 변경하지 않았다. 소스 변경 없이 실행한 회귀 검토여서 Rust 검사를 반복하지 않았다. 기반 r68의 검사는 [모델 선택 검토](model-card-selection-review-2026-10-18.md)에 기록돼 있다.

## 미검증
