# 텍스트 제작 검증

후속 [실제18개 구조화 비교](structured-text.md)에서 형식·근거 ID는 개선됐지만 내용 오류는 남았다. 기존 온도0.8 단발 시험과 별도 조건으로 읽는다.

2026-10-18, [공통 조건](README.md). 실제 ASR 및 Sintel 자막에서 교정·한국어 카드 제목/요약·하이라이트 범위 프롬프트를 만들고 mistral.rs CPU에서 Qwen3 0.6B Q4와 Qwen3.5 0.8B Q4를 실행했다.

초기 교정 입력에 ASR 진단 로그까지 섞이는 문제를 발견해 타임스탬프 대사만 추출하도록 수정했다. 초기 실행과 수정 후 실행의 증거를 구별한다.

| 기능 | 실제 관측 | 승인 상태 |
| --- | --- | --- |
| 교정 | 0.6B가 오인식 문구를 다른 오답으로 바꿈. 0.8B는 string 필드에 배열을 출력 | 자동 적용 미승인 |
| 카드 | 0.6B의 요약 길이/표현 불량. 0.8B는 cue_ids 누락과 내용 환각 | 게시용 결과 미승인 |
| 하이라이트 | 구조상 범위 응답은 가능하나 넓은 대사 전체 선택 | 유용성 미승인 |

온도 0.8 등 엔진 기본 샘플링을 사용했으며 seed 고정 비교가 아니다. 작은 모델의 실행 성공과 JSON 부분 파싱을 스키마·근거·내용 품질 통과로 해석하지 않는다. 원문 cue ID 존재, 시간 범위, 필수 필드와 자료형 검증 뒤 사용자 검토가 필요하다.

구조화 디코딩, 더 적합한 경량 양자화 후보, 한국어 다표본 품질 평가가 남았다. 모델 출력이 외부 셸 명령으로 실행되는 경로는 만들지 않았다. 모델 문구와 구분해 실제 배포 자막을 사용한 [수동 카드·숏폼](manual-export.md)은 후속 별도 실행으로 검증했다.

## Qwen3.5-2B Q4 후속

[ADR010](../../../adrs/player/adr-010-measured-ai-candidates.md)의 고정 repo/revision/LFS 해시를 실제 다운로드에서 검증했다. mistral.rs0.9.4 CPU, context2048, thinking=false, 기존과 동일한3개 프롬프트로 실행했다. VLM의 텍스트 경로만 검증했고 projector/이미지 입력은 실행하지 않았다. 각 task1회, seed 미고정이므로 일반 성능/품질 순위로 쓰지 않는다.

| 작업 | wall, 로드 포함 | 최대 표본 private bytes | 출력 검토 |
| --- | ---: | ---: | --- |
| 교정 | 11.76초 | 2,893,549,568 | uncertain_words가 문자열 배열 대신 중첩 배열. 대사 순서 변경·일부 누락으로 구두점만 교정 조건 위반 |
| 카드 | 16.44초 | 2,945,449,984 | JSON/필수 문자열/유효 cue ID는 통과. 칼의 피·과거 설명을 땅의 특성으로 연결하고 원문에 없는 생각/행동을 추가해 의미 품질 미승인 |
| 하이라이트 | 12.08초 | 2,970,595,328 | cue1·7만 하나의 range로 묶어 연속 구간 조건 위반 |

3개 모두 프로세스 exit0지만 자동 적용/게시 품질은 통과하지 못했다. 파일1.28GB와 실행 약2.9GB를 구별한다. 온도0.8/top-k40/top-p0.95/min-p0.05였고 별도 GPU 실측은 없다.

기존 평가기는 배열 여부와 필드 존재만 검사하므로 중첩 uncertain_words나 불연속 cue 범위를 놓칠 수 있었다. domain 검증에 추가 필드·문자열 원소·빈 값·근거 ID·중복·연속 범위·범위 중복을 추가했고, 교정의 단어 순서/내용 보존을 영숫자 casefold 비교로 별도 표시한다. response 전체 JSON과 첫 object 부분 파싱도 구별한다. 이전 집계는 `evaluation-before-strict-schema.json`으로 보존했다. 최신 evaluation은 cards만 구조/참조 통과이며 교정·하이라이트는 각각 위 오류를 검출한다. 구조 통과가 한국어 의미 통과가 되지는 않는다.
