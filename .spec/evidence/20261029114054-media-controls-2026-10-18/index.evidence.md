# 시청 컨트롤 후속 검증 · 2026-10-18

## 기준과 수정

시각 기준은 `.spec/artifacts/design/v2/viewing/native-player-start-v2.png`다. Rust 확대 도구로 원본의 `(0,876,1586,116)` 하단 영역을 2배 확대해 `runtime/verification/design-crops/start-transport-2x.png`에 보관했다.

- 시작 화면을 검정으로 통일하고 중앙 마크는 낮은 밝기, 파일 열기 아이콘은 앰버로 분리했다.
- 탐색선/볼륨을 공통 `components/media_rail.rs`로 구현했다. 시각 트랙과 원형 손잡이를 32px 입력 영역에서 분리하고, 전폭 탐색선에 붙던 텍스트를 툴팁·접근성 이름으로 옮겼다.
- 미디어가 없을 때 시간은 양쪽 `--:--`, 이전/재생/다음은 비활성이다. 소스 없는 시작 화면의 재생 방식 메뉴를 생략했다.
- 팝오버와 키보드 포커스가 있으면 컨트롤 자동숨김을 보류한다.
- 데모 미리보기는 전체 원본 프레임과 비율을 보존하는 contain 배치로 바꿨다.

## 실제 관측

일반 `runtime/parallel-build/ui/debug/player.exe`를 직접 실행했다. 1180×760 시작 화면에서 원형 손잡이, 전폭 탐색선, 미상 시간, 앰버 폴더 아이콘을 확인했다. 기본 제목줄에서 최대화하여 3440×1392 작업영역으로 전환되고 복원 SVG가 표시됐다. 복원 클릭 후 1180×760과 우측 캡션 정렬로 돌아왔다. 최소화 버튼은 도구가 minimized 상태를 반환했고 활성화 후 원래 창으로 복귀했다. P로 260px 회차 패널을 열고 Esc로 해당 패널만 닫는 것을 확인했다.

볼륨 팝오버의 레일 클릭 후 팝오버가 즉시 닫히는 문제를 발견했다. 원인은 Popup::menu의 CloseOnClick 기본값이며 CloseOnClickOutside로 변경했다. 변경 후 실제 재검증과 키보드 End/Home/화살표는 아직 남아 있다.

최대화 직후 OS 애니메이션 프레임을 최종 렌더로 간주하지 않았다. 추가 캡처에 포함된 16×16 보조 이미지와 주 창을 구별하고, 3440×1392 주 캡처의 screenshotId로 복원 버튼을 조작했다. 이 현상을 제품의 16×16 창 크기 오류로 해석하지 않는다.

## 미검증

변경된 팝오버 지속성·실제 키보드 조절, 데모 폭 프리셋과 좁은 창 설정 패널, 전체 화면별 데이터/선택 상태의 세부 시각 매칭은 후속 검증 대상이다. 재생 중 실제 seek·오디오·자동숨김 타이밍은 이번 무소스 시작 화면 조작으로 검증하지 않았다. VM·DPI는 변경하지 않았다.

## 팝오버 수정 재검증

수정후일반player재실행에서팝오버레일클릭으로80%→67%가되고팝오버가유지됐다. 노란포커스외곽선을확인했고End→100%,Home→0%,Right→1%로변했다. Esc로팝오버만닫히며창과하단컨트롤이유지됐다. 이번변경후cargo test60개통과/5개외부미디어ignored, clippy --all-targets -D warnings와fmt --check통과. 위의팝오버지속성/실제키보드조절미검증항목은이관측으로해소한다.

## 좁은 제작 데모 관측

데모호스트에1440×900/1180×760/980×760/760×480창프리셋을추가했다. OS DPI를바꾸지않고egui viewport InnerSize만요청한다. 실제760×480에서48px아이콘레일,중앙스크롤,고정큐,우측끝캡션과설정버튼을확인했다. 설정창은280px폭으로화면안에들어왔다. 다만데모호스트에Esc입력연결이없어설정창이닫히지않는문제를발견해StudioShell.handle_escape로일반/데모공통입력처리를분리했다. 공유핸들러테스트와실제재검증은진행중이다.

## 공유 Esc와 좁은 탐색 재검증

공유Esc수정후demo재실행,980×760및760×480전환을실제확인했다. 760×480설정창열기→Esc에서설정만닫히고선택작업공간이유지됐다. 아이콘레일의구간감지에focus후Down은자막선택/focus로이동했고End는내보내기선택/focus및하단항목자동스크롤로이동했다. 내보내기의표3행이창안에표시됐다. 설정이닫힌상태에서다음Esc로데모종료를요청했다. 내보내기검색힌트의작업검색→파일검색불일치를수정했다. 1180/1280경계의모든상태및전체12화면상세검토는아직남아있다. 공유핸들러추가후제품test61개통과/5개외부미디어ignored,fmt/clippy통과이며검색문구수정후최종검사를다시수행한다.

최종검색힌트수정뒤fmt --check/cargo test61개통과(외부미디어5개ignored)/clippy --all-targets -- -D warnings를재확인했다. 공유Esc로닫은검토demo의창목록은[]였다. 후속전체범위는 .spec/plans/player/presentation/visual-fidelity-follow-up.md에유지한다.
