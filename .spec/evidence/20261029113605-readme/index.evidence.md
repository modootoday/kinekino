하드웨어는 i9-9900KF, RAM 64GiB, RTX 2070 SUPER 8GB다. 이번 실행은 GPU를 사용하지 않았다. 워커는 하나씩 실행하고 CPU 스레드를 제한했다. 사용자 ChatGPT/Terminal은 종료하지 않았다. 프로세스 최대 메모리는 100ms 간격 표본의 최대 private bytes이며 장치 전체 사용량이 아니다. 비교마다 프로세스는 새로 시작했지만 OS 캐시는 비우지 않았다.

실제 원본은 공개 Sintel 영화와 배포 자막, 한국어 FLEURS test 1개 및 일본어 FLEURS dev의 서로 다른 transcript 3개에 독립 애니메이션 Sprite Fright 영어 혼합 원음4클립을 추가했다. Sprite Fright 배포 자막은 proxy이며 인간 ASR gold가 아니다. 일본어 3개는 모두 MALE 메타데이터이며 서로 다른 화자를 보장하지 않는다. 실제 source 회차·일본어 애니메이션 및 화자 분리 품질 검증은 남아 있다. 입력별 오류와 패딩 수정 전후 결과는 [음성 검증](audio.md)에 기록한다. 설치/다운로드 실패와 품질 실패를 분리해 남긴다. VM·DPI·재생 endurance 시험은 재개하지 않았다.
