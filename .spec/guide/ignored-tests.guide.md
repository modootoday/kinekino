## 요약

2026-10-30 main 기준 `rg '#\[ignore' crates xtask tools`로 전수 조사한 결과 **305개**(kinekino-player 289, kinekino-process 9, kinekino-card-render 3, kinekino-host 2, kinekino-browser 1, kinekino-subtitles 1)다. `docs/continuation/`(이관 보관본)과 `.spec` 문서 안의 문자열은 제외했다. 이 문서는 테스트를 바꾸지 않는다. 모든 테스트는 사유 문자열을 갖고 있으며, 기본 `cargo test`와 CI에서는 실행되지 않는다.

## 분류

| 분류 | 개수 | 뜻 | 기본 실행에서 빠지는 이유 |
|---|---|---|---|
| W 실제 OS 창·IPC·핸들 | 80 | 실제 네임드 파이프·Unix 소켓·창·LocalHost 슬롯을 연다 | 다른 실행과 자원이 겹치면 결과가 오염된다 |
| E 고정 실행 파일·근거 디렉터리 | 73 | 고정(pinned)한 `player-cli`·검증기 바이너리와 새 근거 디렉터리가 필요 | 근거를 새로 남기는 관측 테스트라 배정된 실행에서만 |
| M 실제 미디어 도구·표본 | 68 | 설치된 FFmpeg/FFprobe·mpv·로컬 표본 미디어 사용 | 러너에 도구·표본이 없다 |

| D 디스플레이 | 1 | `DISPLAY` 필요 | 헤드리스 러너 |
| X 기타 명시 배정 | 18 | 위 분류 밖의 개별 배정 관측 | 사유 문자열 참고 |

분류는 사유 문자열의 단어로 기계적으로 나눈 것이라 경계가 겹치는 항목이 있다. 정확한 조건은 아래 전체 목록의 사유를 따른다.

## 실행법

- 통합 테스트(`crates/<crate>/tests/<name>.rs`): `nice cargo test -j 1 -p <crate> --test <name> -- --ignored --exact <테스트 경로>`
- 단위 테스트(`src/` 안): `nice cargo test -j 1 -p <crate> --lib -- --ignored --exact <모듈::경로::테스트>`
- 매크로로 만든 테스트(목록에 "(매크로)" 표시)는 이름이 매크로 인자로 정해지므로 `-- --ignored --list`로 실제 이름을 먼저 확인한다.
- C 분류는 부모 테스트가 띄우므로 직접 실행하지 않는다.
- 한 번에 하나만 실행한다(공유 `/workspace/.cargo-target`, 무거운 작업 1개). 실제 미디어·실사이트 접속·GUI 관측은 승인·배정 항목이며, 이 문서는 실행 허가가 아니다.
- `--include-ignored`로 전체를 돌리지 않는다. 자원 배정과 근거 경로가 테스트마다 다르다.
