# 담당별 참고 WIP

root-tracked.patch와 meari-tracked.patch는 원 Git base에 대한 참고 변경이다. 주 스냅샷에 이미 반영된 변경과 다른 담당 변경이 섞일 수 있으므로 일괄 적용하지 않는다. untracked-index.json의 담당/원 경로/해시로 별도 파일을 확인한다. 소유권과 미검증 상태는 유지한다. 패치의 과거 절대경로는 실행 지시가 아니다.
