# 시각 검토 규칙
- 기준 시안(`.spec/artifacts/design/`, ADR 20261031111316)의 세부 요소를 확대해 1:1로 대응시키고, 실제 실행 화면을 다시 본 뒤에만 시각 일치를 완료로 적는다.
- 시안 이미지의 불일치한 디테일·장식·오류는 복제하거나 기능 규격으로 올리지 않는다.
- 시안 묶음은 화면·상태마다 프레임·간격·아이콘 양식·장식이 어긋날 수 있다(원 님 2026-11-06: 시안 일관성이 다소 낮음). 1:1 대조는 하되, 시안 간 불일치는 기능 규격으로 올리지 않는다.
- 시안끼리, 또는 시안과 이미 정한 토큰·공용 컴포넌트·화면 규칙이 모순되면 구현을 그 예외에 맞추지 않고 일관성 쪽으로 검증·개선한다. 판단은 권고안으로 기록한다.
- 시각 검증 조각(M2-V*)은 대조만이 아니라, 위 불일치로 생긴 화면 차이를 공용 규칙에 맞추는 개선을 포함한다. 목업 재생성은 하지 않는다(보류: UI 시안 작업 재개).
- UI 기준은 PotPlayer. [ADR 20261029113545, evidence 20261029113829]
- 재생목록 패널은 PotPlayer식 검색창·도구줄 없이 시안의 회차 목록 패턴: 헤더, 구분선 있는 평평한 행, 현재 항목 강조, 시안의 폭·색·간격. [사용자 결정 2026-11-03 전달, 근거 문서 없음]
- 구현이 시안과 다르면 지적한다. 그 차이가 시안 간 불일치나 시안 오류에서 온 것이면 시안을 복제하지 않고 일관성 쪽으로 개선한다. 개선 결과는 시안과 나란히 비교한 스크린샷으로 보고. [사용자 결정 2026-11-03 전달, 근거 문서 없음]
- "작품 탐색" 버튼은 탐색 플러그인이 연결된 때만 표시. 호스트는 "탐색 플러그인 연결됨" 상태만 안다. 목업에 두 상태 모두 반영. [ADR 20261031060318-browse-plugins, 20261031104859]
- 브랜드 아이콘은 brand.md. 공통 아이콘은 Meari 공식 카탈로그를 쓰고 출처·버전·해시·라이선스를 보존한다.
- 일관성이 최우선: 프레임·토큰·아이콘·용어·상태를 화면마다 다르게 정하지 않는다.
- 시안에 없는 요소를 더하면(예: 로딩 표시) 보고에 "시안과 다른 점"으로 적는다.
- 기능 검증은 SDK 테스트·CLI로 하고, GUI 검토는 레이아웃·입력·포커스·표시 정합성만 입증한다.
- UI 조각은 단위 테스트·게이트 통과 시 기능 병합 가능, "시각 완료"는 실화면 확인 뒤에만 표시하고 그 전에는 큐·현황표에 "시각 미확인"으로 남긴다. [2026-11-05 원 님 승인; WORK-METHOD.md와 동일]
