모든 AI 기능은 하나의 추론 포트를 부릅니다. 모델을 어디서 돌릴지는 사용자가 고르고, 무언가 컴퓨터 밖으로 나가기 전에 묻고, 한도를 넘기 전에 멈춥니다. 포트 전체가 P1b 계획입니다. `status:planned`

## 모드

- **클라우드**(기본): 호스팅 모델, 가장 빨리 시작.
- **로컬 우선**: 로컬 모델, 로컬 모델이 없을 때만 클라우드.
- **로컬만**: 아무것도 올리지 않음.

## 보호 장치

| 보호 장치 | 기본값 |
|---|---|
| 모드 | 클라우드(로컬 우선, 로컬만으로 변경) |
| 호출당 비용 한도 | $0.50 |
| 전체 / 월간 비용 한도 | $5.00 / $10.00 |
| 지출 전 확인 | 한도의 80% |
| 동의 범위 | 프로젝트(작업, 프로젝트, 항상) |
| 업로드 | 필요한 구간이나 프레임만, 영상 전체는 안 올림 |
| 네트워크 제한 | 연결 10초, 요청 120초, 재시도 3회 |
| 토큰 | OS 자격 증명 저장소에 보관, 설정에는 상태만 표시 |

> [!WARNING]
> 클라우드 모델은 요금이 나갈 수 있습니다. 비용 보호는 한도를 넘은 뒤가 아니라 넘기 전에 작업을 멈춥니다.
