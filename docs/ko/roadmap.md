개발 계획의 단계입니다. 날짜는 약속하지 않습니다.

## 단계

1. **P0 크로스 OS 기반**: 포트, 설정 규약, OS IPC.
2. **P1 코어 컨텍스트**: 재생과 스튜디오 도메인.
3. **P1b 추론 포트**: 로컬·클라우드 모델, 동의, 비용 보호, 자격 증명 저장소.
4. **P2 Linux 재생**: mpv 호스트와 이어 보기.
5. **P3 브라우저 카탈로그**: 소스와 회차 페이지.
6. **P4 스튜디오 실행기**: Linux에서 쇼츠, 카드, 스냅샷.
7. **P5 자막과 AI**: ASS, 음성 인식, 화자 분리, OCR, 번역, 로컬 팩.
8. **P6 GUI**: 설정 화면, Linux 메아리 UI, 마스코트 이벤트.
9. **P7 실모델 평가**: 호스팅 모델 실제 확인.
10. **P9 MCP 서버**: `kinekino mcp serve`, P1b 이후 병렬.
11. **P8 최종 OS 검증**: Windows와 macOS.
